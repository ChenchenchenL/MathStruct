# 《算力约束下大语言模型的质量、配比与资源配置》审阅意见

## 说明

本文档整理对 `01_论文_四问全文_主线重构精修稿.md` 的科学与写作审阅意见，**不讨论图片、附件和证据文件的路径问题**。审阅依据为论文正文、附录以及仓库中现有的 `docs/`、`src/` 和 `result/` 记录；未重新运行全部实验，因此不替代最终复现审计。

## 总体判断

论文作为“多源观测下的条件资源配置框架与敏感性分析”是可行的。它对质量评分误伤、跨尺度失效、半合成资料、算力来源不确定性、随机前沿不可作因果分解等限制披露得比较充分。

但目前不宜把论文定位为“已经验证能够指导真实大语言模型训练的最优资源配置方法”。核心原因是：质量评分尚未完成内容效度校准，第二问的广义损失函数由不同来源分阶段拼接而成，第三问依赖未校准的成本函数，第四问的规模与技术贡献不可识别，Loss 到 Benchmark 的桥接样本也不足以承担长期能力预测。

建议结论为：**大修后可行，当前不建议直接作为强结论论文或竞赛终稿提交。**

## 一、阻塞性问题

### R1-M1 质量评分不能直接作为真实质量变量

**证据位置：** 第 3.2、3.3 节；摘要第 9 行。

论文报告正常公式和代码片段分别被冲突规则降低约 43.9% 和 39.4%，并明确承认没有结构化人工标签校准集。由此，`Q_A` 和 `Q_B` 只能解释为当前指标体系下的相对评分，不能解释为经过人工效度验证的质量真值。

这一问题会沿链条传递到：

- 质量弹性和质量—规模替代关系；
- “质量提高 0.1 可节省 14.9% 参数”的数字；
- `Q*=0.6907` 的预算配置；
- 质量成本和长期能力情景。

**必须修改：**

1. 补充分层人工标注集，至少报告误伤率、召回率、标注一致性和评分校准结果；或
2. 将所有相关结论统一改写为“评分变量变化下的模型内条件结果”，不再称为真实质量提升收益。

### R1-M2 第二问的广义标度律缺少联合识别

**证据位置：** 第 4.1、4.2、4.5 节；公式（4-2）、（4-3）。

B1 主要来自八条训练轨迹，B7 是半合成质量资料，配比响应来自另一组实验，且 `τ_m=0.85` 沿用了旧 ALR 支路的迁移校准。当前资料没有在同一训练协议下联合改变 `N、D、Q、p` 的实验设计。

因此，论文当前能够支持的是分阶段条件模型，不能支持以下更强的解释：

- `ρ` 是真实清洗干预的普适质量收益参数；
- `R(p)` 是独立于规模和质量的领域配比因果效应；
- 14.9% 是真实训练中可实现的参数节省比例；
- 33 项局部互补检查揭示了稳定的领域协同规律。

**必须修改：**

- 将模型名称和结论改成“分阶段估计的条件广义标度律”；
- 在摘要、结论和表 4-5 中明确标注“函数外推”或“模型内等效”；
- 最好增加一个联合小规模训练设计，对 `N、D、Q、p` 至少进行部分交叉变化，验证乘法连接和迁移强度。

### R1-M3 第三问的配置是条件数值解，不是现实最优方案

**证据位置：** 第 5.1、5.3、5.6 节；表 5-1、表 5-3。

差分进化、局部优化、网格和边界检查可以支持数值实现的一致性，但论文自己也承认没有连续域全局最优证明，真实数据清洗成本尚未校准。由此，`0.2021B / 6.2754B token / Q=0.6907` 和 `9.09×10^19 FLOPs` 只能是指定函数、边界和迁移假设下的配置结果。

**必须修改：**

- 将“最优资源配置”统一改为“条件数值配置”或“模型内最优解”；
- 在表题、摘要和结论中同时列出成本函数、质量基线、上下文长度和变量边界；
- 明确数值核验不是全局最优证明；
- 若要提出实际资源建议，必须先用真实清洗流程的单位成本校准三类 `g(Q)`。

### R2-M1 第四问不能稳健分离规模贡献与技术贡献

**证据位置：** 第 6.1、6.3 节；表 6-2。

模型身份、训练阶段和算力来源存在模糊匹配。唯一名称子集只有 64 条记录，其中对话模型数量很少，部分误差参数触及边界。算力份额从 47.53% 到 92.51% 变化，说明分解高度依赖来源情景。

当前对称路径分解保证两项数值相加等于总变化，但不产生因果识别。因此不应把结果解释成“规模贡献”和“纯技术贡献”。

**必须修改：**

- 将“技术贡献”改为“状态项”或“非算力关联项”；
- 将“贡献占比”改为“路径分摊结果”；
- 在摘要和结论中加上“依赖算力来源匹配和模型设定”的限定；
- 若要作因果解释，需要更可靠的训练阶段元数据和历史快照。

### R2-M2 六个月回溯不能证明动态前沿优于简单基线

**证据位置：** 第 6.4 节；表 6-3。

参照前沿月度 MAE 为 4.3495，高于保持基线的 4.0706，这一结果不支持复杂模型优越性。累计最高分 MAE 为 0，主要是因为预测序列被强制施加起报纪录下限，而不是模型成功预测了新纪录。

**必须修改：**

- 从摘要中删除或弱化“累计 MAE=0”；
- 明确说明该指标是带单调性和纪录下限约束的机械结果；
- 增加多个滚动起报点，而不是只使用 2024-09-30 一个起报点；
- 报告滚动 MAE、预测区间覆盖率以及相对于保持基线的差值。

### R2-M3 Loss 到 Benchmark 的桥接样本不足

**证据位置：** 第 6.6 节；图 6-1。

桥接样本只有 75 条，其中 7 条为高可比组，68 条使用不同验证集或近似 Loss。整体 RMSE 为 8.3057 分，高可比小组的低误差不能代表跨族、跨验证集的可靠桥接。

**必须修改：**

- 将图 6-1 和相关段落定位为“指标桥接诊断”，而不是能力预测模型；
- 报告按模型族、验证集口径和训练阶段分层的留出误差；
- 不把第三问的 Loss 配置直接转换成长期 Benchmark 分数；
- 如果没有更多同口径配对，应在摘要和结论中明确桥接链条尚未闭合。

## 二、重要统计与方法问题

### R3-M1 标度参数的精度表达需要收缩

B1 的 1176 条记录来自 8 条完整轨迹。极高的拟合优度和极窄的 Bootstrap 区间主要说明模型能够重建该附件轨迹，不能说明真实训练实验中的参数不确定性同样小。

建议：

- 在正文中把参数区间称为“轨迹条件下的重采样区间”；
- 不把 `R²>0.999999` 写成泛化能力证据；
- 下游优化的敏感性分析应传播参数相关性，而不是只使用独立正态扰动；
- 对 `E、α、β、ρ` 给出跨轨迹或跨来源的稳定性检查。

### R3-M2 配方模型的结构不确定性应进入主要结论

第 3.4 节已经显示，ALR 树、质量坐标树和线性模型对同一占比扰动的方向可以不同。质量坐标是配方的确定性重参数化，不能识别“固定配比下质量提高”的干预效应。

建议：

- 将结构差异纳入主敏感性分析，而不只放在讨论中；
- 对表 4-4 的局部互补结果报告模型分支一致率；
- 不把当前质量坐标树的方向当作唯一配方机制。

### R3-M3 长期情景区间不能称为预测区间

论文已说明长期范围没有传播未来算力路径误差，也没有构造完整的累计纪录轨迹。应把这些范围称为“条件敏感性范围”或“情景端点范围”，而不是 95% 预测区间。

## 三、表达和结构问题

### 1. 摘要混合了观测、拟合和情景推演

摘要同时出现评分稳定性、配方 RMSE、参数节省、互补数量、优化配置、质量边界、算力分解、回溯 MAE 和长期前沿，读者难以判断哪些是直接观测，哪些依赖假设。

建议把摘要按三层重写：

1. 真实数据直接支持的结果；
2. 明确写出假设条件的模型内情景；
3. 一句集中说明质量效度、跨来源迁移和长期外推限制。

例如，`0.2021B、6.2754B token、0.6907` 前应写成：

> 在指数型清洗成本、2048 token 上下文、固定质量基线和指定参数边界下，模型内配置为……

### 2. “建议”“最优”“贡献”应统一降级

全文建议采用以下术语替换：

| 当前容易引起过强理解的表述 | 建议表述 |
|---|---|
| 最优资源配置 | 条件数值配置、模型内最优解 |
| 质量提升带来参数节省 | 评分变量提高时的参数等效变化 |
| 技术贡献 | 状态项、非算力关联项 |
| 领域互补关系 | 指定参考点和转移幅度下的局部互补 |
| 未来能力预测 | 条件前沿情景、外推敏感性分析 |
| 95%预测区间 | 条件范围、情景分位范围 |

### 3. 结论应先写“能支持什么”，再写“不能支持什么”

第七章已经有较好的限制意识，但仍可进一步压缩结论，让每个问题只保留一个可支持命题和一个边界命题。例如：

- 问题一支持冻结评分规则和有限尺度上的配方响应，不支持质量真值；
- 问题二支持分阶段条件损失函数，不支持联合因果效应；
- 问题三支持成本情景下的数值配置，不支持现实全局最优；
- 问题四支持来源敏感的条件分解，不支持技术进步的因果占比。

## 四、AI 使用与竞赛合规风险

**证据位置：** 附录 B。

附录 B 说明 AI 参与了模型候选、公式检查、实验设计、代码诊断、证据整理和正文重写，并承认当前记录不能证明队伍已经完成正式条款要求的独立形成与核验。

这不是文字层面可以修复的问题。提交前必须根据正式赛题规则和真实记录确认：

- AI 是否允许参与核心建模和推导；
- 是否必须披露具体工具、时间和使用范围；
- 核心模型是否必须由队伍独立完成；
- 是否保存了人工复核、运行和修改记录。

不得把未实际发生的人工审阅或独立核验补写进论文。

## 五、建议的修改优先级

### 第一优先级，提交前必须完成

1. 将质量评分定义为未完成人工效度校准的相对指标。
2. 将第二问改写为分阶段条件模型，降低 `ρ`、`R(p)` 和 14.9% 参数节省的结论强度。
3. 将第三问的输出改称条件数值配置，并完整列出成本函数和边界条件。
4. 将第四问的“技术贡献”改成状态项或非算力关联项。
5. 删除或弱化累计 MAE=0 的优越性含义。
6. 将 Loss—Benchmark 桥接改为诊断，不再支持长期能力预测。
7. 完成 AI 使用条款和独立核验资格审查。

### 第二优先级，显著提高可信度

1. 增加滚动起报点和留出回溯。
2. 增加结构化质量人工标注。
3. 增加联合改变规模、数据、质量和配比的训练实验。
4. 对配方模型和广义标度律做结构不确定性传播。
5. 补充按模型族和验证口径分层的 Loss—Benchmark 留出验证。

## 最终结论

论文可以作为一篇“多源数据条件下的资源配置建模与敏感性分析”论文继续完善。当前最关键的不是增加更多模型或更复杂的优化器，而是把结论强度严格压到数据和假设能够支持的范围内，并补足质量效度、联合验证、滚动回溯和桥接留出验证。

在完成第一优先级修改后，论文的科学叙事是成立的；在完成第二优先级补实验后，才有条件进一步主张其对真实训练资源配置的外部有效性。
