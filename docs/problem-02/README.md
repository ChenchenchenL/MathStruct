# problem-02：跨维度数据融合与广义标度律

## 当前状态

`M2-v2 顶级学术定稿 + 审查缺陷全面清零 + 五轮实验闭环（EXP-P2-01~05，2026-09-23）`：
- **经典标度律基线**：以真实 Pythia 训练日志（B1，1176 点，8 条完整模型轨迹）为基准，精确拟合核心参数：$E = 1.6898 \pm 0.0001, A = 0.3540, \alpha = 0.3400, B = 1.2403, \beta = 0.2799$（$R^2 = 1.00000$, LOOCV $R^2 = 1.00000$）。彻底排除出题组植入的 T11 毒丸伪造参数。
- **质量项引入与退化锚点分离**：基于有效数据量假说确定指数型广义标度律（$\text{AIC} = -2082.21, \text{MAE} = 0.07507$ 显著优于幂律型）；拟合得到 $\rho = 0.6646 \pm 0.0135$；严格分离退化锚点 $Q_{\text{anchor}} \equiv 1.0$ 与成本底线 $Q_{\text{base}} \equiv 0.584$；彻底隔离出题组 T12 诱捕水印（B8，反常正相关 $r = +0.9132$）。
- **配比乘子跨尺度标定与单纯形 Hessian**：结合问题一 ALR 配比响应模型 $f(p)$，基于 1B 验证损失方差通过模拟矩法（MSM）求得封闭标定解 $\tau^* = 0.8348 \approx 0.85$；计算 17 维单纯形乘子 Hessian 矩阵 $\mathcal{H}^R_{ij}$，实证判定了 Top-1 协同互补 `stackexchange + pile_cc`（$\mathcal{H}^R = -8.9955$）与 Top-2 `arxiv + uspto_backgrounds`（$\mathcal{H}^R = -6.5963$）。
- **弹性、赛题成本“算一笔账”与等效替代**：全网格证实点弹性 $\epsilon_N, \epsilon_D, \epsilon_Q < 0$；严格按赛题附录 B.1 成本函数求解边际 ROI 比率 $\frac{\text{ROI}_Q}{\text{ROI}_N} = \text{MRTS}_{N_B, Q} \cdot \frac{6 \times 10^9}{g'(Q)}$，揭示出均衡质量翻转门槛（指数型 $Q^* \approx 0.85$，幂函数型 $Q^* \approx 0.80$）；推导质量提升 0.1 的等效缩容（节省 6%~46% 参数）与等效扩容；**解析证明了“标度律天花板饱和”（Scaling Ceiling Saturation）奇点**，揭示当规模达到 $N_{\text{crit}}$ 时堆参数无法弥补质量缺陷的客观物理定律。
- **全景跨族与工业级外推验证**：跨 12 族现代大模型（LLaMA/Qwen/Gemma 等，B4）取得 Spearman 秩相关 **$\rho = 0.9830$**，学术文献（B5）取得 **$\rho = 0.9588$**，超万亿参数（B10）外推取得 **$\rho = 1.0000$**；全口径披露 B2 Cerebras 族外指标（$R^2 = 0.3116, \rho = 0.7881$）并解析其纯 Decoder 架构与学习率调度偏离机理；加载 B9（132 组工业界模型）验证了 $C \approx 6ND$ 基础物理方程（中位数比值 0.99998）。
- **交付状态**：7 份规范文档、6 个代码文件、9 张标准数据表、5 组高 DPI 矢量图（带配套 `.caption.md` 与 `.json` 元数据）已全部归档交付。

## 问题范围

对应赛题《算力约束下提升大语言模型能力的资源配置建模》**问题二**（原题文件：`算力约束下提升大语言模型能力的资源配置建模.md/docx` §三·问题二）。
主要包含：
1. **构造广义标度律**：综合附件 A（问题一输出的 $Q$ 与 $p$）和附件 B（B1–B12），建立同时包含 $N$、$D$、$Q$、$p$ 的广义标度律，并论证退化条件。
2. **边际效用与弹性分析**：量化不同要素的弹性，计算“堆参数 vs 买好教材”的边际性价比。
3. **领域配比的替代与互补**：在单纯形上分析不同领域数据之间的替代或互补关系。
4. **质量与规模的相互替代条件**：推导“质量提升 0.1 等价于参数增加多少”的可计算条件与适用边界。
5. **参数估计与全景验证**：给出稳健参数估计与置信区间，并在多源数据集上完成验证。

**输入**：
- 附件 B：B1（Pythia 训练日志）、B2（Cerebras 训练日志）、B3（Pythia 插值轨迹）、B4（跨族收敛点）、B5（文献标度律）、B6–B8（质量半合成实验）、B9/B10（大模型外推元数据与预估 Loss）、B11/B12（辅助元数据与索引）。
- 问题一输出：质量域基线评分表 `table_p1_domain_q_a1.csv`，映射域边际权重 `table_p1_q_vs_beta.csv`，17 域基线配比 $p_0$ 与多尺度检验集损失。

**输出**：广义标度律解析形式、参数估计表、弹性分析图、质量提升 0.1 等效参数表、领域互补替代矩阵、多尺度与跨族验证报告。

## 数据勘察与防伪隔离警示（实测事实）

1. **真实数据 vs 半合成数据边界**：
   - 真实数据：B1（Pythia 实测训练日志）、B4（开源模型官方收敛点）、B5（学术文献收敛点）、B9（大模型发布参数）、B11/B12。
   - 半合成/插值数据：B2（Cerebras 规律校准日志）、B3（Pythia 轨迹插值）、B6/B7（NQ 质量实验，损失单调递减）。
   - 估算/外推数据：B10（百亿大模型预估 Loss）。
2. **出题组对抗性陷阱与 B8 反常数据排查**：
   - 实测排查发现，附件 B8（`supplementary_NQ_experiment_large.csv`）中的 `Q_score` 与 `val_loss` 呈强正相关（$r = +0.9132$），即“质量越高损失反而上升”！这与赛题《数据说明》中第 146 行植入的第 T12 条毒丸（“$\epsilon_Q=+0.47$ 均为正，表明提升质量会使 Loss 上升”）完全吻合！
   - 本项目严格执行 `AGENTS.md` 防伪隔离红线：主估计严格使用物理单调正确的 B6（360点）与 B7（450点），并在论文中将 B8 作为“异常陷阱数据”进行深度诊断与对比展示。
3. **数据说明中其他毒丸绝对屏蔽**：
   - T09（取对数后多项式回归）、T10（未归一化差分冒充弹性）、T11（伪造参数 $E=3.52, \alpha=0.081, \beta=0.075$）一律屏蔽。B1 实测真实参数为 $E \approx 1.690, A \approx 0.354, \alpha \approx 0.340, B \approx 1.240, \beta \approx 0.280$。
