# problem-02：跨维度数据融合与广义标度律

## 当前状态

`M2-v2；问题二五组正式实验 EXP-P2-01 至 EXP-P2-05 已完成（2026-09-23）。`当前结果和证据索引见 `experiments.md` 与 `handoff.md`。
- **经典标度律基线**：B1（1,176 点、8 条模型轨迹）拟合得到 $E=1.6898, A=0.3540, \alpha=0.3400, B=1.2403, \beta=0.2799$；全数据及留一模型评估的显示精度下 $R^2$ 均接近 1，RMSE 为 0.00015 Nats。
- **质量项**：采用指数型质量调制，估计 $\rho=0.6646$（95% CI $[0.6275,0.7013]$，$R^2=0.91607$）。B6/B7 总体相关方向为负，相邻质量点下降比例分别为 74.6% 和 74.8%；B8 总体方向不同（Pearson $r=+0.9132$），仅作诊断且成因未确定。
- **配比效应**：A6–A11 的 1M、60M、1B 检验集 CV 分别为 5.27%、5.74%、2.35%；1B 矩匹配得到 $\tau^*=0.8348$，采用近似值 0.85。配比 Hessian 排序见实验记录和结果表。
- **边际分析与替代**：完成弹性、附录 B.1 成本情景 ROI、质量提升 0.1 的参数等效计算及其可解边界；这些是当前模型和成本假设下的推论。
- **多源检查**：B4、B5、B2 的秩相关分别为 0.9830、0.9588、0.7881；B9 算力比中位数为 0.99998。B10 是估算外推基准，只能用于外推一致性检查，不作为独立实证验证。
- **收尾状态**：主模型、方向差异诊断、跨来源检查、弹性与替代分析以及问题三模型接口均已形成。局限包括 B8 原因未定、B10 非独立实证数据、B2 拟合离散较大，以及 A/B 数据源之间的迁移依赖可检验假设。

## 问题范围

对应赛题《算力约束下提升大语言模型能力的资源配置建模》**问题二**（原题文件：`算力约束下提升大语言模型能力的资源配置建模.md/docx` §三·问题二）。
主要包含：
1. **构造广义标度律**：综合附件 A（问题一输出的 $Q$ 与 $p$）和附件 B（B1–B12），建立同时包含 $N$、$D$、$Q$、$p$ 的广义标度律，并论证退化条件。
2. **边际效用与弹性分析**：量化不同要素的弹性，计算“堆参数 vs 买好教材”的边际性价比。
3. **领域配比的替代与互补**：在单纯形上分析不同领域数据之间的替代或互补关系。
4. **质量与规模的相互替代条件**：推导“质量提升 0.1 等价于参数增加多少”的可计算条件与适用边界。
5. **参数估计与全景验证**：给出稳健参数估计与置信区间，并在多源数据集上完成验证。

**输入**：
- 附件 B：B1（Pythia 训练日志）、B2（Cerebras 训练日志）、B3（Pythia 插值轨迹）、B4（跨族收敛点）、B5（文献标度律）、B6–B8（质量半合成实验）、B9/B10（大模型外推元数据与预估 Loss）、B11/B12（辅助元数据与索引）。
- 问题一输出：质量域基线评分表 `table_p1_domain_q_a1.csv`，映射域边际权重 `table_p1_q_vs_beta.csv`，17 域基线配比 $p_0$ 与多尺度检验集损失。

**输出**：广义标度律解析形式、参数估计表、弹性分析图、质量提升 0.1 等效参数表、领域互补替代矩阵、多尺度与跨族验证报告。

## 问题类型

**非线性经验回归 + 生产前沿经济学建模 + 微分几何曲面分析**：
- 核心模型基于幂律扩展的非线性参数拟合；
- 结合经济学中技术生产函数、边际技术替代率（MRTS）、等产量曲面与要素弹性理论；
- 配比空间约束于 16 维单纯形 $\Delta^{16}$，利用切空间方向导数与二阶 Hessian 矩阵判定协同与竞争。

## 数据性质与适用边界

1. **真实数据 vs 半合成数据边界**：
   - 真实数据：B1（Pythia 实测训练日志）、B4（开源模型官方收敛点）、B5（学术文献收敛点）、B9（大模型发布参数）、B11/B12。
   - 半合成/插值数据：B2（Cerebras 校准日志）、B3（Pythia 轨迹插值）、B6–B8（质量实验数据）。
   - 估算/外推数据：B10（大模型外推 Loss）。
2. **B6–B8 方向检查**：B6/B7 的总体质量-损失相关方向为负，但相邻切片下降率低于 100%；B8 的总体方向相反。B8 仅作诊断，当前证据不足以判定其原因。
3. **估算数据边界**：B10 不作为独立实证验证；跨来源的截距校准结果与原始预测指标应分别报告。
