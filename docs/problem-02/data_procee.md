# data_procee.md — 问题二数据处理规则清单

> 本文档记录问题二（跨维度数据融合与广义标度律）从原始附件到最终建模输入执行的全部数据处理规则。规则按实际执行顺序编号（P2-01 起），内容自足，可直接供论文预处理小节改写引用。

---

## 规则清单

### P2-01 变量量纲统一与十亿级无量纲化变换
- **适用数据集/字段**：B1（`N_params_B`, `D_tokens_B`）、B2、B4、B5、B6、B7、B8、B9、B10
- **动机**：原始数据中模型参数与 Token 数量常以个（$10^0$）或十亿（$10^9$）混用。为避免数值优化计算中的下溢与条件数恶化，必须统一定义在十亿级（Billion）无量纲基准下。
- **操作定义**：
  $$N = \text{N\_params\_B} \quad (\text{单位：}10^9 \text{ 参数})$$
  $$D = \text{D\_tokens\_B} \quad (\text{单位：}10^9 \text{ Tokens})$$
  $$L = \text{val\_loss} \quad (\text{单位：Nats})$$
  所有导数、弹性与算力换算（Chinchilla $C = 6ND \times 10^{18}$ FLOPs）均以此统一量纲体系为基准同步缩放。
- **输入/输出**：输入混合量纲字段，输出统一在 $[0.07, 10000]$ 区间的标准化连续浮点数。
- **验证**：检查 Pythia 70M 为 0.070542，12B 为 11.965825，量纲完全闭合。

### P2-02 质量方向诊断与 B8 隔离规则
- **适用数据集/字段**：B6、B7、B8（`supplementary_NQ_experiment*.csv`）的 `Q_score` 与 `val_loss`
- **动机**：检查质量评分与验证损失的方向是否与主模型假设一致，并将方向不同的数据保留为诊断样本，不对其具体成因作未经验证的归因。
- **操作定义**：
  1. 计算各质量数据集内部的 Spearman 秩相关系数与 Pearson 相关系数：
     $$r_s = \text{corr}(\text{rank}(Q), \text{rank}(L))$$
  2. 若 $r_s > 0$，将该数据集标记为方向诊断集；是否排除主拟合需结合切片结果、数据性质和模型假设共同决定；
  3. 实测结果：B6 的 Spearman $\rho=-0.3239$、B7 的 $\rho=-0.2990$，相邻质量点下降比例分别为 74.6% 和 74.8%；B8 的 Spearman $\rho=+0.9208$，方向与 B6/B7 不同；
  4. 规则决断：质量参数主估计使用 B7 全量 450 点，B6 用于方向对照，B8 保留为诊断集，不参与主拟合；B8 的具体成因未确定。
- **输入/输出**：过滤前 2,514 点，过滤后保留单调自洽的 450 点（B7 全量）参与质量参数主拟合。
- **验证**：主拟合数据 B7 的固定切片相邻质量点下降比例为 74.8%，总体 Pearson 与 Spearman 相关均为负；不将该结果表述为逐点单调。

### P2-03 完整模型轨迹隔离与留一验证规则（LOOCV）
- **适用数据集/字段**：B1（`pythia_training_log_existing.csv`）的 8 个不同规模模型
- **动机**：大模型训练日志具有强时间自相关性，随机抽样会导致相邻步数（step）数据泄露，造成高估模型泛化性能。
- **操作定义**：
  按 `N_params_B`（或模型规格 70M, 160M, 410M, 1.0B, 1.4B, 2.8B, 6.9B, 12B）将 1,176 行数据严格划分为 8 组独立模型轨迹；
  进行留一模型交叉验证（Leave-One-Model-Out Cross-Validation, LOMOCV）：轮流将 1 个完整模型的全部 147 个 step 作为未见测试集，其余 7 个模型的全部数据作为训练集进行拟合与泛化评估。
- **输入/输出**：输入 1176 行时间序列点，输出 8 折严格族内留出外推误差指标。
- **验证**：留一验证 RMSE 与全量拟合 RMSE 的相对膨胀率低于 15%，证实标度律对未见参数规模具有坚固的内插与泛化能力。

### P2-04 早期训练 Warmup 阶段截断对比规则
- **适用数据集/字段**：B1 各模型的初始训练 step
- **动机**：赛题明确要求“检查早期训练是否偏离幂律，若限定适用训练区间，必须说明并保留全数据对照”。深度学习早期 warmup 阶段由于学习率爬升与梯度剧烈震荡，往往偏离渐近幂律分布。
- **操作定义**：
  设定截断阈值对比：
  - 口径 A（全数据对照）：保留 step 64 起的全部数据（$D \ge 0.134$B Tokens，n=1,176）；
  - 口径 B（稳定训练区间）：剔除早期非稳态步骤，仅拟合 $D \ge 1.0$B Tokens（step $\ge 500$，n=1,152）；
  - 口径 C（高度成熟区间）：拟合 $D \ge 5.0$B Tokens（n=1,128）。
- **输入/输出**：报告三口径下的参数拟合值 $(E, A, \alpha, B, \beta)$ 与残差分布。
- **验证**：实测三口径下参数漂移极小（$E$ 保持 1.6898~1.6901，$\alpha$ 保持 0.3400，$\beta$ 保持 0.2800，全数据下 $R^2 = 1.0000$），说明全数据与截断数据的拟合参数在本样本范围内一致。

### P2-05 跨尺度配比方差收缩比与模拟矩法（MSM）标定规则
- **适用数据集/字段**：问题一真实检验集 A6–A11（1M、60M、1B 尺度）的验证损失均值与标准差
- **动机**：用独立检验集的跨尺度损失变异度校准配比迁移强度系数 $\tau$，减少仅凭先验设定参数带来的不确定性。
- **操作定义**：
  1. 提取各尺度配方实验的损失相对变异系数：
     $$\text{CV}_{\text{scale}} = \frac{\sigma(L_{\text{scale}})}{\mu(L_{\text{scale}})}$$
  2. 计算由小模型（1M）至大模型（1B）的相对方差收缩比：
     $$\text{Ratio} = \frac{\text{CV}_{1\text{B}}}{\text{CV}_{1\text{M}}} = \frac{2.35\%}{5.27\%} \approx 0.4466$$
  3. 利用模拟矩法（MSM）求解跨尺度迁移参数 $\tau^*$：
     在 1B 测试集上评估模型相对变异 $\text{rel\_diff} = \frac{f(p)-f(p_0)}{f(p_0)}$，实测样本标准差 $\text{std}(\text{rel\_diff}) = 0.02708$。
     一阶线性解为 $\tau_{\text{linear}} = \frac{\text{CV}_{1\text{B}}}{\text{std}(\text{rel\_diff})} = 0.8686$；
     非线性精确标定解为 $\tau^* = \arg\min_\tau |\text{std}(\exp(\tau \cdot \text{rel\_diff})) - \text{CV}_{1\text{B}}| = 0.8348 \approx \mathbf{0.85}$。
     建立涵盖 $\tau \in [0.45, 1.50]$ 的全区间敏感性对照表。
- **输入/输出**：输入 1M/60M/1B 真实数据分布，输出实证校准后的无量纲常数 $\tau^* = 0.85$。
- **验证**：在 $\tau^* = 0.85$ 时，模拟分布与 1B 实测 CV 绝对误差仅 0.00045，且保持在基准配比处的无损退化。

### P2-06 跨族与跨来源基线截距对齐规则
- **适用数据集/字段**：B2（Cerebras）、B4（跨族现代模型）、B5（学术文献模型）、B10（超大规模外推）
- **动机**：不同开源模型家族具有不同的架构设计（如 RoPE、SwiGLU、Grouped Query Attention）与不同大小的词表分词器（Tokenizer），会导致绝对损失存在系统性的基线截距偏移 $\Delta E_{\text{source}}$。
- **操作定义**：
  在保持标度律核心幂指数 $\alpha, \beta$ 固定的前提下，允许针对不同来源估计一个固定的基线平移项：
  $$L_s(N, D) = E + \Delta E_s + A N^{-\alpha} + B D^{-\beta}$$
  其中 $\Delta E_s = \text{median}\left( L_{\text{obs}} - (E + A N^{-\alpha} + B D^{-\beta}) \right)$；重点考察去偏移后的残差 RMSE、解释方差比与跨族秩相关性。
- **输入/输出**：输入跨族异构损失，输出消除词表与架构基线差异后的统一相对评价。
- **验证**：去截距偏移后，跨族大模型（LLaMA、Qwen、Gemma 等）的相对标度收敛曲线与 Pythia 标度律保持极高一致性（Spearman $\rho = 0.9830, R^2 = 0.8286$）；B2 Cerebras 保持强秩一致性（$\rho = 0.7881, \text{RMSE} = 0.4185$ Nats, $R^2 = 0.3116$）。

### P2-07 奇点饱和数值保护与存在性截断规则
- **适用数据集/字段**：等效规模扩容计算式（M2-EQ04 语义二）
- **动机**：当模型规模达到或超过临界阈值 $N_{\text{crit}}$ 时，分母为零或负数，直接计算将导致负数开非整数幂产生复数或数值报错。
- **操作定义**：
  在计算 $N_{\text{equiv}}$ 前，先计算临界判定指标：
  $$\text{Residual\_Margin} = A N^{-\alpha} - T \left( 1 - e^{-0.1 \rho} \right)$$
  - 若 $\text{Residual\_Margin} > 10^{-6}$：处于有限可解区，执行标准幂次求解：
    $$N_{\text{equiv}} = \left( \frac{A}{\text{Residual\_Margin}} \right)^{1/\alpha}$$
  - 若 $\text{Residual\_Margin} \le 10^{-6}$：标记为“奇点饱和区（Scaling Ceiling Saturation）”，输出符号 $\infty$（无解），并在输出表格中记录“不可替代（Irreplaceable）”。
- **输入/输出**：输入 $(N, D, Q)$ 状态，输出数值稳定的等效参数量或饱和标记。
- **验证**：在典型测试用例中准确捕获奇点，杜绝计算异常与复数污染。
