# decisions.md — 问题三技术决策与方法选型记录

> 本文档依据《数学建模项目总规范》建立，详述问题三（算力约束下的多维资源联合优化与结构性转移）的关键建模决策、算法选型及对比论证。

---

## 决策记录清单

### D3-01 求解策略选型：单调性解析降维消元 vs 软约束外罚函数法
- **背景**：赛题存在高维非线性约束 $d [(6+\eta L_{\text{ctx}})n + \bar{h}(Q)] \le \bar{C}$。若直接采用固定罚系数的外罚函数或稠密网格枚举，既难以严格控制预算残差，也缺乏连续最优性条件支持。
- **方案比选**：
  - 方案 A（罚函数 / 拉格朗日启发式）：在目标中添加 $\lambda \max(0, C_{\text{total}} - C)$，需要反复调整惩罚超参数，极易因梯度不平滑导致震荡，无法保证最终解严格满足约束；
  - 方案 B（单调性解析降维消元，**本项目采纳**）：利用标度律对数据量 $d$ 的严格单调递减性，解析得到最优解处必有 $d^*(n, Q) = \frac{\bar{C}}{(6 + \eta L_{\text{ctx}}) n + \bar{h}(Q)}$。代回目标函数后，直接将约束优化转化为对数空间 $(\ln n, Q)$ 的无约束/盒约束优化。
- **决策理由**：方案 B 数学上严格等价于原约束规划的最优前沿，消除了一个核心决策维度，保证约束残差 $|C_{\text{spent}} - C|/C < 10^{-12}$，同时计算效率提升数千倍，支持 50 点细密预算谱的快速精准扫描。

### D3-02 归一化量纲体系：十亿/EFLOPs 基准量纲系
- **背景**：原始变量 $N \in [10^6, 10^{12}], D \in [10^8, 10^{14}], C \in [10^{18}, 10^{25}], h(Q) \in [0, 4 \times 10^9]$ 跨越十余个数量级，极易引发浮点下溢或矩阵病态。
- **决策内容**：
  - 定义 $n = N / 10^9, d = D / 10^9, \bar{C} = C / 10^{18}, \bar{h}(Q) = h(Q) / 10^9$；
  - 使得所有变量均落在 $[0.001, 1000]$ 的良态数值区间；
  - 严格证明 $\bar{C} = d [(6 + \eta L_{\text{ctx}}) n + \bar{h}(Q)]$ 在两端同时具有 EFLOPs 量纲，杜绝单位不闭合。

### D3-03 领域配比 $p$ 的处理范式：两种固定配比情景对比与 $\tau$ 显式敏感性分析
- **背景**：赛题明确指出“领域配比 $p$ 可作为联立决策变量，也可由前两问结果确定，但须说明理由”。
- **决策内容**：
  1. **固定配比情景设定**：在主优化中不将 $p$ 设为自由内点寻优变量，而是对比两种代表性固定配比情景：
     - 情景一：基准配比 $p_0$（A4 中 The Pile 原始配比的平均向量，$R=1.0$；不是等比例均匀配比）；
     - 情景二：问题一多尺度交叉验证确定的推荐优化配比 $p_{\text{opt}}$（在名义值 $\tau=0.85$ 下 $R(p_{\text{opt}})=0.9602$）。
  2. **决策理由与证据边界**：调整配比本身不直接产生额外算力消耗（$C_p = 0$）。若在第三问对 $p$ 开展无约束或弱约束的自由内点寻优，极易使决策点漂移出 A4–A15 数据集的凸包支持域，导致代理模型产生严重的外推幻觉。固定配比可保证决策方案严格扎根于实证支持域内。同时明确说明：$p_{\text{opt}}$ 的效果是在跨数据源迁移假设下的条件结果，属于名义校准，而非独立识别出的普适最优配比；
  3. **$\tau$ 网格敏感性分析**：在情景范围 $\tau \in [0.45, 1.50]$ 的五个取值 $\{0.45,0.65,0.85,1.15,1.50\}$ 上重算最优配置（`tab_p3_tau_sensitivity.csv`）。该范围并非统计置信区间；中高预算结果只显示在这些网格点上的相对变化较小。

### D3-04 成本函数比较机制：原始量纲基准 vs 几何形态基准对齐（$\Delta Q = 0.1$）
- **背景**：附录 B.1 提供的三类成本函数中，$\gamma_{\text{exp}} = 10^7, \gamma_{\text{pow}} = 5 \times 10^9, \gamma_{\text{log}} = 2 \times 10^9$，原始量纲系数跨越两个数量级。直接比较会将“量纲规模假象”与“函数本征凹凸性”混为一谈。
- **决策内容**：
  - 设计双层对比体系：
    1. **层级一（赛题原始参数基准）**：严格按赛题附录 B.1 默认参数求解低、中、高预算下的配置；
    2. **层级二（纯几何形态基准对齐）**：在基准提升幅度 $\Delta Q = 0.1$ 处（$Q = 0.684$），对齐使得三类函数的增量清洗成本完全相等（$\bar{h}_{\text{pow}}(0.684) = \bar{h}_{\text{log}}(0.684) = \bar{h}_{\text{exp}}(0.684)$），进而对比其二阶导数与曲率差异对最优配置演化的纯几何驱动机制。

### D3-05 结构性转移（Structural Shift）科学判据：三重可证伪数学准则
- **背景**：在连续规划中，支出份额和配置通常是平滑变化的，单纯断言“存在结构性转移”极易沦为主观臆断。
- **决策内容**：
  - 设立三层互补验证体系：
    1. **区制跃迁准则**：设立容差 $\varepsilon_Q = 0.005$，定量划分粗放区制（$Q^* \le Q_0 + \varepsilon_Q$）、集约区制（$Q_0 + \varepsilon_Q < Q^* < 1 - \varepsilon_Q$）与饱和区制（$Q^* \ge 1 - \varepsilon_Q$）；
    2. **变点数值识别**：对支出份额 $s_Q(\ln \bar{C})$ 拟合两相分段折线回归（Broken-stick Model），并对固定扫描点作 1000 次有放回重抽样，报告折点与斜率变化量的经验分位范围。该范围只衡量扫描网格重加权下的稳定性，不作为总体置信区间或显著性检验；
    3. **对数缩放弹性偏离**：检验扩张弹性 $\kappa_n, \kappa_d$ 是否偏离经典 Chinchilla 常数弹性。

### D3-06 连续资源优化方法选择
- 利用损失对数据量的单调性解析消元，将约束问题降为二维连续优化；采用多起点 L-BFGS-B，并以差分进化作数值交叉核验。
- 结果由所选标度律、成本函数及变量边界决定。由于未建立全局凸性证明，交叉核验仅作为数值证据，不宣称对任意非凸实例均保证全局最优。

### D3-07 不确定性分析定位：假设参数扰动情景压力测试 vs 经验后验分布
- **背景**：EXP-305 评估标度律参数估计误差对资源配置的潜在影响。若将扰动称为“后验协方差传递”或“后验置信区间”，则暗示其协方差矩阵来自完整贝叶斯反演，存在过度断言风险。
- **决策内容**：
  - 将 EXP-305 严格定位为“**假设参数扰动情景分析与敏感性压力测试**”；
  - 使用问题二给出的 $A,\alpha,B,\beta,\rho$ 边际标准误，构造相互独立的正态扰动情景；该实现没有使用参数协方差结构，因此不是联合参数不确定性的完整传播；
  - 每档预算生成 1000 个扰动情景，对全部情景计算固定方案损失，对前 100 个情景求数值参考最优解并计算相对后悔度；后悔度均值、95% 分位数和样本最大值仅对应该 100 个子样本；
  - 因参考解通过未作全局验证的数值优化器得到，结果应称为相对数值参考解的样本后悔度，不称为严格 Minimax 风险或全样本最优后悔度。

### D3-08 数据质量边界饱和（$Q^*=1.0$）的模型依赖性与实证非严格单调性说明
- **背景**：中高预算下最优质量均收敛至上限 $Q^*=1.0$。若不加说明直接作为无条件工程结论交付，易被评审专家质疑脱离实际。
- **决策内容**：
  - 明确指出该结论受广义标度律单调负指数项 $e^{-\rho(Q-1)}$ 的数学形式约束；
  - 对照问题二对半合成附件 B6/B7 的分析：固定切片相邻质量点的损失下降比例分别为 74.6% 与 74.8%；该诊断不应被表述为真实清洗过程的普遍规律；
  - $Q^*=1$ 仅为当前模型形式下的条件结论。现有实验未识别工程质量目标区间或证明 $0.85\sim0.95$ 可捕获某一确定比例的收益，因此不作这类定量工程承诺。
