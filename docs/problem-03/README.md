# 问题三：算力约束下的多维资源联合优化与结构性转移

## 1. 问题概述与定位

本模块针对 2026 年中国研究生数学建模竞赛 F 题第三问展开建模与实证求解。

在真实大模型预训练中，给定总算力预算 $C$（如 $10^{19}, 10^{22}, 10^{24}$ FLOPs），如何在模型参数量 $N$、训练数据量 $D$、数据质量 $Q$ 与领域配比 $p$ 之间进行最佳资源分配，并分析当预算变化时最优分配是否发生质变（“结构性转移”），是本问的核心决策问题。由于上下文长度 $L_{\text{ctx}}$ 由下游任务和模型架构外生给定（依据附件 C7），长文本注意力开销会随序列长度显著增加，进而侵蚀可用于基础训练和数据清洗的预算空间。

本问紧密承接前两问成果：
- **继承问题一成果**：依据附录 B.1 正文授权，采用开放网络抓取域（Common Crawl + C4）合成中位数质量 $Q_0 \equiv Q_{\text{base}} = 0.584$ 作为未经额外处理的原始语料清洗基线；将问题一多尺度独立检验优选的推荐配方 $p_{\text{opt}}$ 与 The Pile 原始配比（A4 平均配比）$p_0$ 作为两种固定配比情景进行对照；$p_0$ 不表示 17 个领域等比例的均匀配比；
- **继承问题二成果**：广义标度律参数 $E = 1.6898, A = 0.3540, \alpha = 0.3400, B = 1.2403, \beta = 0.2799, \rho = 0.6646, \tau^* = 0.85$（名义校准值）；
- **解决核心科学问题**：
  1. 建立单位严格自洽闭合的归一化算力约束多维资源配置优化模型；
  2. 利用目标函数单调性解析消去数据量 $D$，将连续优化降维至二维对数参数-质量空间，并以多起点局部优化和差分进化进行数值交叉核验；
  3. 对比两种固定配比情景，并在 $\tau \in [0.45, 1.50]$ 上采用五点敏感性网格，评估迁移系数变化对配置的影响；
  4. 解析推导注意力开销与基础训练开销平价平衡的理论临界阈值 $L_{\text{ctx}}^{\text{crit}} = \frac{6}{\eta} = 30,000$ Tokens，并在 C7 实测窗口上定量测算算力折扣；
  5. 对比附录 B.1 三类清洗成本函数，并通过 $\Delta Q = 0.1$ 基准对齐消融实验揭示函数形态（凸/凹）对内点清洗均衡的本质决定性；
  6. 提出“边界区制跃迁 + 支出份额分段回归/Bootstrap 变点 + 弹性漂移”三重可证伪准则，科学判定“结构性转移”；
  7. 根据问题二参数标准误构造独立高斯扰动情景，开展参数敏感性压力测试；每档预算对 100 个扰动情景求解 oracle 配置，其余 900 个情景用于名义策略的损失分布评估。

## 3. 方法范围与适用边界

- 资源配置采用连续有界优化；利用 $d$ 的单调性解析消元，使用多起点 L-BFGS-B，并以差分进化进行数值交叉核验。数值核验支持所报告解，但不构成对非凸问题全局最优性的普遍解析证明。
- 领域配比仅作两种固定情景比较：$p_0$ 为 A4 中 The Pile 原始配比的平均向量，$p_{\text{opt}}$ 为问题一识别的推荐配方；不在问题三中对配比作自由内点寻优。
- 迁移系数敏感性覆盖区间 $[0.45,1.50]$ 的五个离散网格点。该区间是情景扫描范围，不是置信区间；结论只对已计算网格点成立。
- 质量边界 $Q^*=1$ 是所采用单调质量项模型下的条件结果。B6/B7 属半合成数据，局部相邻质量点的变化率不应外推为真实清洗过程的普遍工程规律。
