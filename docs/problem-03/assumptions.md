# assumptions.md — 问题三建模假设与适用边界

> 本文档依据《数学建模项目总规范》建立，详尽记录问题三（算力约束下的多维资源联合优化与结构性转移）所依赖的核心假设、假设动机、支持证据、潜在局限及敏感性/证伪检验方案。

---

## 1. 假设清单与详细论证

### 假设 A3-01：Chinchilla 算力代理有效性假设（Compute Proxy Validity）
- **假设陈述**：大语言模型基础预训练浮点运算量满足标准 Chinchilla 代理公式 $C_{\text{train}} = 6 N D$。
- **物理与理论依据**：
  - 在标准 Transformer 自回归架构中，每个 Token 的前向传播包含约 $2N$ 次浮点运算（主要由自注意力的 QKV 投影、输出投影与 MLP 的两个升维/降维线性层贡献）；
  - 反向传播梯度计算与参数梯度累积约需 $4N$ 次浮点运算；
  - 合计单步训练需要 $6N$ FLOPs/Token。此经验公式在 Kaplan (2020)、Hoffmann (2022) 及赛题说明中均被公认为行业标准黄金基准。
- **适用边界**：适用于标准 Dense Transformer 架构。对于 MoE（混合专家模型）或结构化剪枝模型，激活参数量不等于总参数量，本公式需乘以激活稀疏比，但在本题 Dense 模型范围内完全精确。

### 假设 A3-02：有效数据量严格单调性与预算约束活跃假设（Active Budget Constraint）
- **假设陈述**：在变量处于合理物理边界内部时，验证集损失 $L$ 关于训练 Token 数 $d$ 严格单调递减（$\frac{\partial L}{\partial d} < 0$），最优决策必将总算力预算 $\bar{C}$ 完全耗尽（$\bar{C}_{\text{total}} = \bar{C}$，即预算约束严格活跃）。
- **数学依据**：
  - 广义标度律中数据项为 $T(d, Q) = B d^{-\beta} e^{-\rho(Q-1.0)} R(p)$；
  - 实证标定参数 $\beta = 0.2799 > 0, B = 1.2403 > 0$；
  - 因此 $\frac{\partial L}{\partial d} = -\beta \frac{T}{d} < 0$ 在定义域内恒成立。
- **证伪边界**：当 $d$ 触及数据墙硬上限 $d_{\max}$ 且 $n$ 和 $Q$ 均触碰物理天花板时，算力无法继续被有效吸收，预算约束可能变为松弛；实测表明在赛题设定的 $10^{19} \sim 10^{24}$ FLOPs 预算谱内，可吸收算力上限 $\bar{C}_{\max} \approx 6.4 \times 10^8 \gg 10^6$，预算约束恒活跃。

###假设 A3-03：清洗基线与理论退化锚点双重解耦假设（Baseline vs Anchor Decoupling）
- **假设陈述**：数据质量的经济成本计费基线 $Q_0 \equiv Q_{\text{base}} = 0.584$ 与广义标度律的理论退化锚点 $Q_{\text{anchor}} \equiv 1.0$ 具有完全独立的物理内涵，必须严格解耦。
- **支持证据**：
  - $Q_0 = 0.584$ 来源于附件 A1 全量样本质量评分的中位数（代表未经额外昂贵清洗的原始网络抓取语料质量）。附录 B.1 明确规定清洗算力为增量成本 $C_Q = D [g(Q) - g(Q_0)]_+$，因此在 $Q = Q_0$ 时 $\bar{h}(Q_0) = 0$，表示零额外清洗支出；
  - $Q_{\text{anchor}} \equiv 1.0$ 代表完美无噪的理想数据上限，仅在此处广义标度律退化为经典 Chinchilla 公式；
  - 问题二模型消融证明：若将退化锚点强行错设为 $0.584$，由于强行引入了 $\exp(\rho \times 0.416) \approx 1.32$ 倍的人为偏置，导致 $R^2$ 由 0.9161 骤降至 0.7827。

### 假设 A3-04：长文本注意力算力线性代理假设（Attention Compute Proxy）
- **假设陈述**：长文本注意力开销由赛题给定公式 $C_{\text{attn}} = \eta N D L_{\text{ctx}}$ 准确表征，其中 $\eta = 2 \times 10^{-4}$，上下文长度 $L_{\text{ctx}}$ 由模型架构外生决定。
- **物理机制**：
  - 标准自注意力计算复杂度为 $O(N D L_{\text{ctx}})$（对每个 Token 需对上下文窗口内的 $L_{\text{ctx}}$ 个 Token 做点积注意力运算）；
  - $\eta$ 反映了自注意力矩阵乘法在整个网络浮点运算中的相对硬件常数；
  - 注意力开销直接消耗浮点预算，与基础训练和清洗共享同一总预算池。

---

### 假设 A3-05：配比乘子迁移名义校准与固定情景假设（Mixture Transfer Nominal Calibration）
- **假设陈述**：
  1. 领域配比调节乘子 $R(p) = \exp\left\{ \tau^* \cdot \frac{f(p) - f(p_0)}{f(p_0)} \right\}$ 采用 $\tau^* = 0.85$ 作为问题二在 1B 检验集（A8）上的经验校准名义值；跨来源、跨更大预算的绝对稳定性尚未被独立实验直接验证；
  2. 因此，固定优质配比 $p^*_{\text{opt}}$ 下的配置解属于跨数据源迁移假设下的**条件最优结果**，而非独立识别出的跨全尺度普适最优配比；
  3. 主方案直接设定为基准配比 $p_0$ 与固定推荐配比 $p^*_{\text{opt}}$ 两种离散情景对照。
- **敏感性与证伪检验**：
  - 针对 $\tau$ 的跨尺度外推风险，在情景范围 $[0.45,1.50]$ 上的五个网格点进行重计算敏感性分析（详见 `tab_p3_tau_sensitivity.csv`）；该范围不是置信区间。中高预算下所测试网格点的 $Q^*$ 均为 1，参数与数据规模相对名义方案偏差不超过约 5.1%，损失变化不超过约 0.008 Nats。该结论仅适用于已测试的五个取值和当前模型。

---

### 假设 A3-06：单调指数质量项模型条件性假设（Monotonic Quality Form Model-Conditionality）
- **假设陈述**：数据质量对模型损失的物理收益满足指数型广义标度律 $B D^{-\beta} \exp\{-\rho(Q - Q_{\text{anchor}})\}$ 的严格单调递减函数形式。
- **与原始数据的证据边界说明**：
  - 问题三求解所得的最优质量 $Q^*$ 是在该**“单调指数质量项”模型假定**下求得的理论最优解；
  - 问题二对半合成实验集 B6/B7 的固定切片分析显示，相邻离散质量采样点的损失下降比例分别约为 **$74.6\%$ 与 $74.8\%$**，并非逐点严格单调；该比例不代表真实清洗过程的普遍发生率；
  - 因此，交接与结论中不得将 $Q^*$ 表述为“真实数据已证明质量提升在所有微观情形下必然降低 Loss”，而应科学表述为“在宏观有效数据量假说与单调标度律模型框架下的条件最优资源配置”。
