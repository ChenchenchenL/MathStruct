## 1. 核心数学模型体系与量纲自洽闭合

### 1.1 统一十亿/EFLOPs 基准量纲系（P0-1 严格闭合）
为彻底消除原始量纲跨越十余个数量级的数值病态与单位混淆，统一定义归一化物理变量：
- **模型参数量**：$n = N / 10^9$（十亿参数，$\text{Billion params}$）；
- **训练数据量**：$d = D / 10^9$（十亿 Token，$\text{Billion tokens}$）；
- **算力预算**：$\bar{C} = C / 10^{18}$（$\text{EFLOPs}$，即 $10^{18}\text{ FLOPs}$）：
  - $C = 10^{19}\text{ FLOPs} \implies \bar{C} = 10$；
  - $C = 10^{22}\text{ FLOPs} \implies \bar{C} = 10000$；
  - $C = 10^{24}\text{ FLOPs} \implies \bar{C} = 1000000$；
- **增量质量成本**：$\bar{h}(Q) = [g(Q) - g(Q_0)]_+ / 10^9$（$\text{GFLOPs/Token}$）；
- **长文本注意力系数**：$\eta = 2 \times 10^{-4}$。

> **清洗基线质量 $Q_0 = 0.584$ 的严密溯源与聚合定义**：
> 附录 B.1 明确规定：$Q_0$ 表示未经额外处理的基准数据质量（可由附件 A 质量评分或合理假设给出）。在问题一中，各领域多维质量中位数显示：arXiv 0.727、Common Crawl 0.650、Books 0.564、StackExchange 0.511、C4 0.510、Wikipedia 0.433、GitHub 0.337（全样本未加权中位数 $\approx 0.500$，The Pile 官方配比加权 6 域中位数 $\approx 0.543$）。在大语言模型工业界预训练中，超过 80%~85% 为开放网页爬虫数据；因此将 $Q_0$ 严格标定为**开放网络抓取域（Web-scraped Baseline: Common Crawl + C4）的合成中位数质量**（$Q_0 \equiv \text{Median}(Q_{\text{cc}} \cup Q_{\text{c4}}) \approx 0.584$）。此设定具有清晰的物理意义：模型直接摄取公网爬虫原始语料不发生清洗算力开销（$\bar{h}(Q_0) = 0$），超越此底线进行精细化过滤时才产生增量算力支出。

**归一化预算闭式**：
$$d \left[ (6 + \eta L_{\text{ctx}}) n + \bar{h}(Q) \right] \le \bar{C}$$
括号内各项单位严格为 $\text{GFLOPs/Token}$，乘以 $d$（$10^9\text{ Tokens}$）恰好等于 $10^{18}\text{ FLOPs}$（$1\text{ EFLOP}$），两端量纲绝对自洽闭合。

### 1.2 单调性解析消元与降维优化（M3-EQ02）
因为标度律关于训练 Token 量严格单调递减（$\frac{\partial L}{\partial d} < 0$），在变量物理边界内最优解处预算约束严格活跃（$\lambda > 0$）。因此可完全解析消除 $d$：
$$d^*(n, Q) = \frac{\bar{C}}{(6 + \eta L_{\text{ctx}}) n + \bar{h}(Q)}$$
领域配比 $p$ 设为两种固定情景（基准配比 $p_0$ 与优化配比 $p_{\text{opt}}$），将原问题降维为在对数参数空间 $u = \ln n$ 与质量空间 $Q$ 的二维有界连续优化：
$$\min_{u \in [\ln 0.001, \ln 1000.0], \, Q \in [0.584, 1.000]} \tilde{L}(u, Q) = E + A e^{-\alpha u} + B \left[ \frac{\bar{C}}{(6 + \eta L_{\text{ctx}}) e^u + \bar{h}(Q)} \right]^{-\beta} e^{-\rho(Q - 1.0)} R(p)$$

> **配比与转移强度的条件性声明**：
> 本文对配比的影响比较基于两种固定情景：$p_0$ 为附件 A4 中 The Pile 原始配比平均向量（$R=1.0$，并非 17 个领域等比例配比）；$p_{\text{opt}}$ 为问题一多尺度交叉检验下识别的推荐配方（名义校准值 $\tau=0.85$ 时 $R(p_{\text{opt}})=0.9602$）。$p_{\text{opt}}$ 的效果是跨数据源迁移假设下的条件结果，不是独立识别出的普适最优配比；配比不直接计入本模型的 FLOPs 成本。

### 1.3 边际替代率（MRTS）均衡与边界区制（M3-EQ03）
对内点解，质量投资一阶条件严格对消数据量，呈现出尺度不变的边际均衡方程：
$$\rho = \beta \frac{\bar{h}'(Q)}{(6 + \eta L_{\text{ctx}}) n + \bar{h}(Q)} = \beta \frac{g'(Q)/10^9}{(6 + \eta L_{\text{ctx}}) n + \bar{h}(Q)}$$
- **区制 I（粗放扩展期 $Q^* = Q_0$）**：若在基线处边际清洗成本过高使得边际收益不足，质量停留在基线；
- **区制 II（集约清洗期 $Q_0 < Q^* < 1.0$）**：清洗收益与规模收益达到精细动态平衡；
- **区制 III（质量饱和期 $Q^* = 1.0$）**：质量触碰理论上限，边际预算完全回流至扩大 $N$ 与 $D$。

### 2.3 $Q^*$ 边界饱和结论的模型依赖性与实证边界说明
在指数型与幂函数型成本下，中高预算的最优质量均收敛于理论上限 $Q^* = 1.0$。必须明确指出：
- **模型形式驱动性**：广义标度律采用了严格单调的负指数项 $e^{-\rho(Q-1.0)}$，该数学结构设定了“数据质量越高，模型损失单调严格越低”的先验。在此平滑数学模型下，只要算力充裕，质量投资必会推升至上边界；
- **数据证据边界**：问题二对半合成附件 B6/B7 固定切片的分析显示，相邻离散质量点损失下降比例分别约为 74.6% 与 74.8%；该结果不属于真实清洗过程的直接观测，也不能解释为一般工程中的局部波动发生率。
- **论文撰写口径**：$Q^*=1.0$ 是当前单调负指数质量项和成本函数设定下的模型条件最优解。现有分析未确定现实场景的推荐质量区间，也未证明 $Q=0.85\sim0.95$ 可捕获某一确定比例的质量收益；工程阈值需由对应数据与清洗成本另行校准。

## 3. 结构性转移的科学识别与验证（EXP-302 核心产出）

对算力在 $10^{18} \sim 10^{25}$ FLOPs 跨越 7 个数量级扫描 50 个连续采样点，获得以下三项关键证伪证据：
1. **边界区制跃迁预算**：
   - 指数型成本在 $C_{\text{trans1}} = 1.00 \times 10^{19}$ FLOPs 处自区制 I 跃迁至区制 II（开始集约清洗）；
   - 在 $C_{\text{trans2}} = 1.00 \times 10^{20}$ FLOPs 处跃迁至区制 III（质量触顶饱和）；
2. **两相分段折线回归（Broken-stick Model）与扫描点稳定性分析**：
   - 支出份额序列 $s_Q(\ln \bar{C})$ 拟合分段回归测得结构性突变拐点为：
     $$C_{\text{crit}} = \mathbf{3.73 \times 10^{19}} \text{ FLOPs} \quad (R^2 = 0.8519)$$
   - 对 50 个确定性预算扫描点作 1000 次有放回重抽样，折点重抽样区间为 $[1.93 \times 10^{19}, 7.20 \times 10^{19}]$ FLOPs。因扫描曲线不是随机抽取的独立观测，该区间仅作为扫描点扰动下的探索性稳定性摘要，不解释为总体置信区间；当前检验也不支持报告结构性转移的显著性 $p$ 值。
3. **扩张弹性的物理收敛**：
   - 越过结构性转移拐点后，由于质量单价恒定，模型扩张弹性 $\kappa_n$ 与数据扩张弹性 $\kappa_d$ 平滑收敛至 Chinchilla 理论常数 $\kappa_n \to 0.4515, \kappa_d \to 0.5485$。

$$C_{\text{attn}} = C_{\text{train}} \iff \eta N D L_{\text{ctx}} = 6 N D \iff L_{\text{ctx}}^{\text{crit}} = \frac{6}{\eta} = \mathbf{30,000} \text{ Tokens}$$

## 5. 成本函数本征几何形态对比（EXP-304 核心产出）

在基准提升点 $\Delta Q = 0.1$（$Q = 0.684$）处对齐清洗成本后：
- **严格凸性（指数型）**：边际成本急剧暴增，强制小模型必须在内点实现精细的 ROI 动态平衡（低档预算下 $Q^* = 0.6907$）；
- **凹性（对数型）**：边际成本单调递减（“越洗越便宜”），在任何预算下均直接跳跃至理论天花板 $Q^* = 1.0$；
- **量纲对齐修正**：消除量纲尺度干扰后，幂函数型在低预算下亦平滑进入内点清洗区制（$Q^* = 0.672$），证实其与指数型共享相同的凸性均衡机制。
