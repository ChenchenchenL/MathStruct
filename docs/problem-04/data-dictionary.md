## 3. 样本筛选与分层口径（严格区分两级样本池）

### 3.1 两级样本池口径严格定义（P0-1 闭合）
- **口径一：许可证开源池（约 2400 席）**：
  - C1 中 Hub License 明确标为开源/学术许可（`apache-2.0`, `mit`, `llama3*`, `gemma*`, `qwen*`, `cc-by*` 等）的所有模型；
  - 该池主要用于开源生态全景统计与基准分布特征刻画；
- **口径二：算力可分析交集池（数百席，以 EXP-401 实测为准）**：
  - 经 P4-01 三级匹配漏斗（L1 官方桥接 447 席 + L2 规范化碰撞 + L3 规则校验）成功关联 C4 训练算力、且算力非缺失的开源模型；
  - 只有该交集池具备训练算力 $C_i$、评测得分 $S_i$ 与时间戳 $t_i$，是 SFA 动态前沿估计与因果分解的**唯一合法样本**。

### 3.2 模型类型分层（Pretrained vs Chat/Finetuned）
- **基座预训练模型组 (`pretrained`)**：
  - C1 `Type` 中标注为 `🟢 pretrained`（共 275 个）；
  - 纯净反映自回归标度扩展规律，是规模弹性 $b$ 的主要识别锚点；
- **对话与指令微调模型组 (`chat/finetuned`)**：
  - C1 `Type` 中标注为 `💬 chat models`（718 个）与 `🔶 fine-tuned`（1785 个）；
  - 叠加了指令对齐的额外结构性红利；
- **合并模型 (`merges`, 1724 席)**：
  - 独立标记为衍生分支，在 EXP-401 输出分布对照，不并入主前沿拟合。

### 3.3 C6 桥接数据覆盖域与外推区域界定（P0-2 闭合）
- **实测覆盖域**：$L \in [1.65, 2.84]$ Nats, $S_{\text{avg}} \in [3.80, 47.98]$ 分；
- **外推区域**：$S > 47.98$ 分；未来预测目标（55–80 分）在能力端属于纯外推。
