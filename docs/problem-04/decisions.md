# decisions.md — 问题四技术决策与方法选型记录

> 本文档依据《数学建模项目总规范》建立，详述问题四（技术演进分析与前沿预测）的关键方法选型、技术决策、对抗性诱捕（T17–T20）防范机制及备选方案论证。

---

## 决策记录清单

### D4-01 动态前沿建模范式：有界动态随机前沿（SFA）为主，时间平滑高分位回归为备
- **背景与诱捕识别**：出题组在第 5、9、13 页植入 T17（建议将得分按 10 分一段离散化并用马尔可夫矩阵外推）与 T18（建议直接用 ARIMA 对序列外推，不做规模与技术分解）。
- **方案比选**：
  - 方案 A（马尔可夫转移矩阵 / ARIMA，出题组诱捕建议）：粗暴破坏连续演进动力学，且无法回答规模与非规模的因果拆解设问；
  - 方案 B（普通 OLS 均值回归）：拟合的是平均模型能力，无法刻画开源前沿边界的真实突破；
  - 方案 C（有界动态随机前沿 SFA，**本项目主选**）：将能力残差拆解为对称度量误差 $e_i$ 与单侧前沿差距 $d_i$，直接估计前沿生产包络面，并建立局部状态空间方程跟踪技术演变；
  - 方案 D（带时间惩罚的 95% 高分位面板回归，**本项目备选**）：无分布假设，直接对条件分位数寻优，与 SFA 形成稳健交叉印证。
- **决策理由**：方案 C 严格契合微观计量前沿生产理论，天然支持技术非效率与前沿的分离；方案 D 用于消除复合残差分布偏态的敏感性疑虑。

### D4-02 因果贡献分解方法：反事实 Shapley 排序平均分解法（隔离 T19 假参数）
- **背景**：题目明确要求“分离并分别量化规模扩张与非规模技术进步各自的贡献占比”。出题组在 T19 伪造反常识参数 $b_N = -6.2, b_t = 0.02$。
- **方案比选**：
  - 方案 A（直接简单系数相除）：忽略了非线性 Logit 变换下的边际非对称性与变量先后改变的顺序效应；
  - 方案 B（反事实 Shapley 排序平均分解法，**本项目采纳**）：
    构建 4 个反事实状态（旧算力旧技术、新算力旧技术、旧算力新技术、新算力新技术），计算两种改变顺序下的平均边际增量：
    $$\Delta_C = \frac{1}{2} \{ [F(C_1, t_0) - F(C_0, t_0)] + [F(C_1, t_1) - F(C_0, t_1)] \}$$
    $$\Delta_{\text{tech}} = \frac{1}{2} \{ [F(C_0, t_1) - F(C_0, t_0)] + [F(C_1, t_1) - F(C_1, t_0)] \}$$
- **决策理由**：Shapley 分解具有完美的公理化性质（有效性、对称性与可加性：$\Delta_C + \Delta_{\text{tech}} \equiv \Delta_{\text{total}}$），彻底消除了因变量先后调整导致的主观偏置。

### D4-03 Loss-to-Benchmark 连续单调饱和桥接（彻底隔离 T20 虚假正相关）
- **背景**：出题组在 T20 声称“Loss 与 Benchmark 相关系数 $r = +0.68$ 为正相关”。
- **实证核查**：在 C6 扩展数据集上实测验证，所有 6 个单项基准及综合分与 Val_Loss 的相关系数均在 $[-0.51, -0.86]$ 之间，相关系数显著为负！
- **桥接形式选型**：
  - 弃用高次多项式（防止 Runge 振荡），采用物理合理的 **连续有界负指数 Logistic 映射**：
    $$S_k(L) = \frac{100}{1 + \exp(-(a_k - b_k L))} \quad (b_k > 0)$$
  - 采用留一模型家族交叉验证（LOFOCV）评估跨家族泛化能力；对 C6 的 7 个高可比同源样本与 68 个中可比样本分别拟合，量化跨源截距漂移。

### D4-04 时间轴口径与预测起报点锚定决策
- **决策内容**：
  1. **主时间轴（观测能力轴）**：采用 C1/C2 的 `Submission Date`（精确至日，覆盖 2024-06 至 2025-03）。原因：提交日期代表该模型在该基准测试集上能力被客观验证并记录的时刻；
  2. **敏感性时间轴（立项/发布轴）**：采用 C4 的 `Publication date`，对仅有年份的记录严格保持年精度，杜绝捏造假月份；
  3. **预测起报点**：严格设定为观测数据集最后有效记录日 **$T_0 = 2025\text{-}03\text{-}13$**，预测 $+12$ 个月（至 2026-03）与 $+24$ 个月（至 2027-03），坚决不使用运行代码时电脑的当前系统时间作为时间锚点。

### D4-05 样本开源口径与 Pretrained / Chat 分层决策
- **决策内容**：
  1. **开源权重口径**：以权重文件公开发布、且具有学术研究或复现许可为主样本池（约 2000+ 席）；对纯闭源商业 API 模型单列敏感性对照；
  2. **模型类型严格分层**：
     - 基座组（`pretrained`，275 席）：反映纯净的预训练标度扩展能力；
     - 对齐微调组（`chat/finetuned`，2503 席）：反映经过人类偏好对齐（RLHF/DPO）与指令微调后的综合工程实力；
     - 在动态前沿模型中引入分层哑变量 $v_{\text{chat}}$，量化指令对齐带来的结构性上抬效应（预计抬升 $5 \sim 15$ 分）。

### D4-06 C8 逐任务底层聚合复核决策（BBH 官方规则还原）
- **决策内容**：
  - 从 C8 的 1863 个模型原始测试 JSON 中读取 BBH 24 项子任务；
  - 严格依据官方规则执行有效样本量加权平均：
    $$S_{\text{BBH}}^{\text{raw}} = \frac{\sum_{j=1}^{24} N_j \cdot \text{acc}_j}{\sum_{j=1}^{24} N_j}$$
  - 实证测定其与 C1 报告分数的转换式为：
    $$S_{\text{BBH}}^{\text{norm}} = \frac{S_{\text{BBH}}^{\text{raw}} - 27.96}{100 - 27.96} \times 100$$
  - 回归判定系数 $R^2 = 0.9982$，以无可辩驳的证据链解释了 28% 随机猜测基线扣除与归一化四舍五入。

### D4-07 算力放缓定量化与三种条件情景设定
- **决策内容**：
  - 基于 2023–2025 年前沿开源模型的实测训练算力回归年化增长率 $g_C$；
  - 设立三档可证伪情景：
    - 情景 1（历史动量）：年化增速保持 $g_C$；
    - 情景 2（增速减半）：年化增速为 $0.5 g_C$；
    - 情景 3（算力停滞）：算力封顶，$g_C = 0$；
  - 在三种情景下分别预测前沿边界，量化“若硬件算力封顶，纯靠算法与数据工程还能支撑大模型能力提升多少”。

### D4-08 与前三问形成闭环：路径 A（动态前沿）vs 路径 B（标度律-桥接）对偶验证
- **决策内容**：
  - **路径 A**：直接通过动态前沿模型推演未来综合能力前沿；
  - **路径 B**：将情景算力 $C(t)$ 代入第三问的最优资源配置模型求得最优损失 $L^*(C)$，再代入式 (10) 桥接模型求得 Benchmark 预测得分；
  - 建立两条路径在历史重叠期的回测检验，客观报告两者的理论残差，揭示“纯预训练损失降低”与“多维综合基准演进”之间的技术跃迁差。
