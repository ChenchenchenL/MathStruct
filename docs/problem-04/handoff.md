# 问题四交接：M4-v2.1 / EXP-408

旧版交接稿已归档于 `review/problem04_rebuild/handoff_legacy_pre_exp408.md`，只供审计，不作为当前论文结论来源。当前使用题面问题四与附录 A 的连续综合分、规模和时间关联分解、算力放缓情景要求。C8 逐任务聚合与 C6 Loss–Benchmark 桥接由 EXP-401/402 独立负责；本次 EXP-408 没有重新估计它们，也没有把桥接输出接入纪录预测，因此不能称已经完成全题闭环。

## 预测对象与数据

- 数据版本：`D4V2-C1-C2-C3-C4`；文件哈希、环境和代码哈希见 `result/problem04/v21/exp408_manifest.json`。C1/C2 逐行身份校验；资格、去重和 C4 时间一致匹配分别按 `data_procee.md` 的 P4V2-01/02；C3 按 P4V2-04 只作可比性审计。
- 主对象是合格开源模型在每月底的**累计最高 C1 综合分**，不是当月新模型最高分，也不是条件能力面。时间轴是榜单提交日，2024-06 至 2025-03；截止日为 2025-03-13。综合分 0–100 分，不能与 C3 早年不同协议得分直接合并。
- C1 原始 4,576 行，资格筛选 1,850 行，同名首次提交去重后 1,805 行。可信且发布时间不晚于提交日的 C4 匹配为 113 行、64 个不同 C4 身份，接受的未来日期匹配为零。模型级规模分解只对这个小交集成立；整个纪录序列使用 1,805 行入选模型。C4 Token 数已在匹配审计表中保留，但未作为方程的独立解释变量；资格使用 C1 许可和 C2 开放权重字段。故本次尚未穷尽题面附录 A 对 C4 数据量与开放权重的分析要求。
- C3 共 4,599 行；26 条历史来源记录中 23 条至少一项基准为零，缺失单元为零。零分可能包含未评测占位，不能按真实零能力解释，也不能用于扩展同口径的 12/24 个月验证窗。逐年、来源和逐基准审计见 `result/tables/problem04/exp408_c3_year_source_audit.csv`。

## 模型与验证

- `model.md` 的 M4V2-EQ01 定义资格与单调累计纪录；M4-v2.1 平滑 0.90 pinball 方程建立给定训练 FLOPs、提交月、类型及家族的**条件上分位能力面**。算力系数约束为非负，相同 C4 身份总训练权重为 1。代码入口是 `src/problem04/exp08_frontier_quantile.py`，并复用 `src/problem04/exp07_frontier_v2.py` 的冻结筛选、匹配、纪录、均值对照和算力情景实现。
- 九个家族逐一留出时，上分位模型的加权 pinball 损失为 0.1017（Logit 单位），均值模型为 0.3274；上分位覆盖率分别为 0.783 与 0.407。上分位模型更适合此**模型级条件分位评价**，但 0.783 低于名义 0.90，不能称为已校准的 90% 预测界。
- 2024-10 至 2025-03 的六个单月累计纪录测试点均未刷新纪录。同目标 MAE：持平 0.000、训练期平均增量 1.550、均值条件模型 0.577、上分位条件模型 0.923 分。三个月的四个可评价测试点也无纪录更新，对应 MAE 为 0.000、5.442、1.658、2.626 分。按预先登记的选择规则，**主点预测是持平**，从 2025-03-13 起报的 12/24 个月均为 51.2313 分。这是短窗口基线选择结果，绝非“未来不会进步”的论断。
- 上分位面上的条件历史分解：首末月 90% 算力分位由 $3.696\times10^{23}$ 至 $3.506\times10^{24}$ FLOPs；模型内总位移 14.871 分，其中算力关联位移 9.927 分（66.76%）、时间关联位移 4.943 分（33.24%），Shapley 加和残差为零。该比例依赖家族构成、许可筛选、稀疏 C4 匹配和函数形式；时间系数还可能吸收 Token 规模、架构、数据工程、评测组成及选择偏差，**不是可识别的纯技术因果贡献**。
- 12/24 个月三档算力放缓下的上分位条件数值，及 200 次 C4 身份重采样的参数敏感范围，见 `result/tables/problem04/exp408_scenario_forecast.csv`。它们是固定模型关系下的条件变化，不是经过长期时间外检验的点预测或覆盖率已校准区间。当前资料不能支持“完美预测”。
