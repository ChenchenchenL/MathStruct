# data_procee.md — 问题一数据处理规则

> 本文件按 AGENTS.md 规范记录数据处理规则，措辞自足，可供论文写作者直接改写为论文的“数据预处理与特征工程”小节。规则按实际执行顺序编号 P01–P10，并以 P05a 补充缺失值约定；数值结果需在更新代码重跑 EXP-05 后重新核对。

---

### P01 流式读取与大文本在线提取
- **适用数据集/字段**：A1（抽样集）、A2（arxiv 扩展集）、A3（github 扩展集）的 `.jsonl.xz` 压缩文件。
- **动机**：原始文件解压后总体积超过 1.6 GB（A3 单文件逾 20 万行），一次性解压缩载入内存耗费资源；且 `content` 大文本字段主要用于在线统计与人工抽查，无须全量入库。
- **操作定义**：采用 Python 内置 `lzma.open()` 逐行流式读取，使用 `json.loads()` 在线解析 22 个质量指标字段，大文本 `content` 仅在抽查时切片采样，其余在内存中即刻丢弃。源域标签按规则提取：A1 读取 `_source_domain` 字段；A2/A3 无域字段，直接绑定文件名推断域（arxiv/github）。
- **输入/输出**：输入为压缩 JSONL 文件；输出为包含数值指标与元数据 ID 的内存 DataFrame，A1 为 51,230 行，A2 为 17,523 行，A3 为 203,752 行。
- **验证**：行数与字段数与赛题说明及勘察结果逐行完全吻合，内存占用控制在 500 MB 以内。

### P02 列表型指标的结构化降维压缩（M1-EQ07–11）
- **适用数据集/字段**：A1–A3 中 8 个多维列表型质量指标（`fineweb_edu`, `fluency_en`, `ad_en`, `modernbert_*` 4 项, `qurater`）。
- **动机**：赛题明确要求“部分指标为多维列表型，须先压缩为标量后再参与建模”，且分量具有不同语义（logits、等级概率分布或多方面评分），不可盲目取均值。
- **操作定义**：
  1. `fineweb_edu`（1 维）：取唯一分量标量值 $s_{\text{edu}} = x[0]$（M1-EQ07）。
  2. `fluency_en`（2 维 logits，官方顺序 [not_fluent, fluent]）：取正向 logit 差 $s_{\text{flu}} = z_2 - z_1$（M1-EQ08）。
  3. `ad_en`（2 维 logits，官方顺序 [has_ad, no_ad]）：取无广告度 logit 差 $s_{\text{adfree}} = z_2 - z_1$（M1-EQ09，正向指标）。
  4. `modernbert_*`（4 项，6 维 PRRC logits 0–5 级）：计算 softmax 期望等级并归一化到 [0, 1]：$s = \frac{1}{5}\sum_{l=0}^5 l \cdot \frac{e^{z_l}}{\sum e^{z_m}}$（M1-EQ10）。
  5. `qurater`（4 维 QuRating）：解包为 4 个独立维度（`qur_ws`, `qur_re`, `qur_ft`, `qur_ev`），各自归一化后参与方向判定与等权合成（M1-EQ11）。
- **输入/输出**：输入为 8 个变长列表字段；输出为 11 个标量连续特征，单位为无量纲或对应量纲差。
- **验证**：EXP-03 验证现代 BERT 期望等级与 argmax 等级的一致性，Spearman 相关系数达 0.914–0.939，round-match 匹配率达 81.4%–95.6%，连续期望等级具有更高的区分度。

### P03 指标方向统计校验与入选集筛选（M1-EQ21）
- **适用数据集/字段**：22 个质量特征（经 P02 展开后为 25 个特征候选项）。
- **动机**：赛题要求“指标方向须统一为‘越高越好’”。部分标量（如长度、词汇丰富度、大写比例）和专业度特征属于文本风格而非通用质量，其优劣方向存在领域依赖性，不能主观预设。
- **操作定义**：以语义天然正向的五维（`fineweb_edu`, `fluency`, `reasoning`, `readability`, `cleanliness`）等权均值构建基准分 $x^{\text{base}}$。在 A1 抽样集的 7 个质量域内，分别计算各候选特征与基准分的 Spearman 秩相关 $\rho_d$。若在 $\ge 4/7$ 个域中 $\rho_d \ge 0.2$，判为正向；若在 $\ge 4/7$ 个域中 $\rho_d \le -0.2$，判为负向；其余判为方向不定，剔除出主合成加权集 $S$。
- **输入/输出**：输入为各特征原始值；输出为方向校验判定表。
- **验证**：EXP-01 与 EXP-03 实测：最终判定 15 项正向指标（Base 5 + dsir 3 项 + 4 项 qurater + professionalism + word_count + unigram_entropy）；2 项负向指标（`rps_doc_frac_unique_words`, `rps_doc_frac_no_alph_words`）；8 项方向不定剔除。入选特征集 $|S| = 17$。

### P04 DSIR 特征的文本长度混杂消除（AS-03）
- **适用数据集/字段**：`dsir_books`, `dsir_math`, `dsir_wiki`。
- **动机**：DSIR 重要性得分为负对数似然类指标，量纲为 $-10^3 \sim -10^5$，且随文本长度呈强烈负线性衰减（EXP-03 实测与 $\ln(1+\text{word\_count})$ 的 Spearman 达到 $-0.889 \sim -0.913$，斜率约 $-5000/\text{log-word}$），导致未残差化前被严重误判为“负向”。
- **操作定义**：以 $\ln(1+\text{word\_count})$ 为解释变量，对 A1 样本上的三项 DSIR 特征建立最小二乘回归，提取残差作为长度无关的真实重要性信号：
  $$\text{resid}_i = \text{dsir}_i - (\hat{\alpha} + \hat{\beta} \ln(1+\text{wc}_i))$$
  该回归系数 $\hat{\alpha}, \hat{\beta}$ 在 A1 上拟合并冻结，直接迁移应用至 A2 和 A3。
- **输入/输出**：输入为受长度混杂的大负数；输出为去长度相关性的纯净重要性残差。
- **验证**：残差化后重新进行 M1-EQ21 检验，三项 DSIR 特征在 6/7 个域中均与基准质量转为显著正相关（$\rho_d \in [0.23, 0.70]$），完全恢复其原本的语义正向性。

### P05 经验分位数标尺映射与尺度冻结（AS-11）
- **适用数据集/字段**：入选集 $S$ 中的 17 个质量特征。
- **动机**：不同指标量纲迥异（百分比、计数值、logit 差、残差），且存在长尾厚尾；Min-Max 极易受极端异常值破坏。
- **操作定义**：在 A1 抽样集上计算每个特征在 1001 个等分格点上的经验分位数，建立单调分位数映射标尺 $F_k^{-1}$。负向指标执行题目指定的补转换（$\tilde{x} = 1 - r$）。该分位数映射网格在 A1 上拟合后完全冻结，应用于扩展集 A2/A3 时使用分段线性插值计算，严格禁止重新在 A2/A3 上拟合。
- **输入/输出**：输入为任意量纲的指标值；输出为严格落在 $[0, 1]$ 内、方向均为“越高越好”的无量纲相对秩得分。
- **验证**：EXP-05 在 A2/A3 全量样本上验证插值稳定性，无外推越界，特征分布高度一致。

### P05a 缺失值处理与有效维度记录
- **适用数据集/字段**：A1–A3 的 25 个压缩候选特征及最终入选集 $S$。
- **动机**：A1 中最高字段缺失率约为 0.025%，不能让缺失值处理隐含在均值函数的默认行为中。
- **操作定义**：对每个样本，仅在可用的入选特征上计算等权平均，并以该行可用特征数重新归一化权重；若 $S$ 中没有可用特征，则 $Q_i$ 记为缺失。冲突度对可用的 C1–C4 分量取最大值；若四个分量均缺失，则冲突标签记为缺失。
- **输入/输出**：输入为分位数映射后的特征矩阵；输出为 $Q_i$、有效特征数和冲突有效分量数。
- **验证**：正式运行时记录有效特征数分布、缺失样本数和各域剔除数量；A1–A3 采用同一规则。

### P06 质量冲突度计算、工作阈值与 Hinge 降权修正（M1-EQ18/19）
- **适用数据集/字段**：样本级质量评价。
- **动机**：当样本同时出现极端对立属性（如高教育价值伴随高商业广告，或高推理价值伴随高无序符号）时，线性加权会掩盖质量瑕疵；必须显式建模冲突并对冲突样本适度惩罚。
- **操作定义**：
  1. 计算 4 组语义冲突对：$c^{(1)} = \sqrt{\text{edu} \cdot \text{ad\_strength}}$（教育×广告，其中广告强度为 $1-\text{adfree}$）；$c^{(2)} = \sqrt{\text{edu} \cdot \max(\text{rep}, \text{noalph})}$（教育×重复/非字母噪声）；$c^{(3)} = \sqrt{\text{flu} \cdot (1-\text{clean})}$（流畅×整洁度低）；$c^{(4)} = \sqrt{\text{reas} \cdot \text{rep}}$（推理×简单重复）。
  2. 综合冲突度 $\tilde{c}_i = \max(c^{(1)}, c^{(2)}, c^{(3)}, c^{(4)}) \in [0, 1]$。
  3. 工作阈值 $\tau$ 定为 A1 冲突度分布的 P95 分位点（$\tau = 0.8736$）；该选择由候选分位点扫描和 top-50 原文定性抽查支持，但未形成带人工标签的准确率/召回率校准集。
  4. Hinge 超额惩罚项 $h_i = \max(0, \tilde{c}_i - \tau)/(1 - \tau) \in [0, 1]$。
  5. 综合质量分：$Q_i = \left(\frac{1}{|S|}\sum_{k \in S} \tilde{x}_{ik}\right)(1 - \lambda h_i)$，取 $\lambda = 0.5$。
- **输入/输出**：输入为 17 维归一化指标；输出为样本级综合质量分 $Q_i \in [0, 1]$ 及冲突标签。
  - **验证**：EXP-03/05 对 top-50 冲突样本进行原文定性抽查，观察到商业软文宣传（C1）与论文代码/公式标记（C2）等典型结构；该抽查不是结构化人工标签校准。$\lambda$ 敏感性测试表明域级排序对惩罚强度稳健（Spearman=1.0），因此将 $\lambda=0.5$ 作为默认分析值，不宣称其已由人工排序指标标定。

### P07 域级质量统计聚合与双口径报告（M1-EQ20，协议第 6 条）
- **适用数据集/字段**：A1（7 域）、A2（arxiv 扩展）、A3（github 扩展）。
- **动机**：由于文本存在长尾离散性，中位数比均值更具稳健性；赛题强制要求使用全量 A2/A3 记录，同时独立性检验要求排除与 A1 重叠样本。
- **操作定义**：各域质量综合评价值以样本中位数为主统计量：$Q_d = \mathrm{median}\{Q_i : s(i)=d\}$，并报告离散度 $\mathrm{disp}_d = \mathrm{IQR}\{Q_i\}$。对扩展集 A2/A3，同时报告：
  - **Protocol A（全量口径）**：直接计算全量样本的域中位数，满足赛题义务；
  - **Protocol B（去重独立口径）**：过滤掉与 A1 同 ID 的样本（arxiv 重叠 8.10%，github 重叠 4.91%）后计算，检验独立泛化性。
- **输入/输出**：输入为样本级 $Q_i$；输出为各域的标量 $Q_d$ 及统计区间。
- **验证**：EXP-05 实测表明 Protocol A 与 Protocol B 的中位数差异 $<0.0001$，且与 A1 对应域中位数高度一致（arxiv 0.7277 vs 0.7271，github 0.3362 vs 0.3371）。

### P08 配比数据千分位误差修复与单纯形归一化（AS-08）
- **适用数据集/字段**：A4–A15 配比表（17 个 `train_the_pile_*` 字段）。
- **动机**：受原始 CSV 浮点存储四舍五入影响，配比行和在 $0.996 \sim 1.003$ 之间波动，破坏单纯形和为 1 的严格数学约束。
- **操作定义**：在数据接入模型前执行行归一化修正：
  $$\tilde{p}_{jd} = \frac{p_{jd}}{\sum_{k=1}^{17} p_{jk}}$$
- **输入/输出**：输入为原始配比矩阵；输出为严格满足 $\sum_{d=1}^{17} \tilde{p}_{jd} = 1$ 且 $\tilde{p}_{jd} \ge 0$ 的标准单纯形成分矩阵。
- **验证**：归一化后行和最大绝对误差 $< 10^{-15}$。

### P09 标量验证损失目标构建（M1-EQ14，AS-04）
- **适用数据集/字段**：A5、A7、A9、A11、A13、A15 中的 13 列验证集损失 `metric/the_pile_*_val_loss`。
- **动机**：下游包含 13 个验证子域，缺乏唯一的标量 Loss 指标；为供问题三进行标量算力分配寻优，须定义全局代表性损失。
- **操作定义**：以 13 个有验证集记录的域等权平均作为主回归标量目标：
  $$y_j = \frac{1}{13}\sum_{d \in \mathcal{V}} \ell_{jd}$$
  并保留各域独立多输出模型作为并列对照视角。
- **输入/输出**：输入为 13 列逐域损失；输出为标量验证损失 $y_j$（nat）。
- **验证**：EXP-04 敏感性实验证实等权均值 $y$ 与配比加权损失趋势高度一致，且不引入对 $p$ 的循环内生性。

### P10 加性伪计数平滑与加性对数比（ALR）变换（M1-EQ15/16）
- **适用数据集/字段**：配比成分矩阵 $\mathbf{P}$。
- **动机**：配比数据存在大量零值（稀疏单纯形），无法直接取对数；且单纯形闭合性导致直接线性回归存在完全共线性。
- **操作定义**：
  1. 采用伪计数平滑替换零值：$\tilde{p}_{jd} = \frac{p_{jd} + \varepsilon / 17}{1 + \varepsilon}$，基准参数取 $\varepsilon = 10^{-3}$（敏感性考察 $10^{-4}, 10^{-2}$）。
  2. 选取均值占比最大的域 `pile_cc` 为参考基准，执行 16 维 ALR 变换：
     $$x_{jd} = \ln\left(\frac{\tilde{p}_{jd}}{\tilde{p}_{j,\mathrm{ref}}}\right), \quad d \in \{1,\dots,17\}\setminus\{\mathrm{ref}\}$$
- **输入/输出**：输入为 17 维单纯形成分数据；输出为 16 维无约束欧氏空间解释变量矩阵 $\mathbf{X}$。
- **验证**：EXP-02 实测更换参考域（`pile_cc`, `wikipedia_en`, `arxiv`），回归预测值与 CV $R^2$（0.1904）严格不变，证明了 ALR 变换对参考域选择的内蕴不变性。
