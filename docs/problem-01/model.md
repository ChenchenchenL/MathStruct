## M1-v2（2026-09-23，取代 v1 的 EQ12/13 与验证段；EQ15 更名；新增 EQ18–EQ21。修订依据：第二轮审查四项 + 术语修正）

**v1→v2 变更摘要**：
1. **冲突惩罚对齐判定阈值**：v1 的 EQ12 对所有样本减 λc_i，与"冲突判定"语义不一致且 Q 可能 <0。v2 改为 **hinge 超额冲突 + 乘性降权**（M1-EQ18），并给出 Q∈[0,1] 的解析证明。
2. **验证协议去标签泄漏**：模型选择限 A4/A5 内部交叉验证；A6/A7 做独立同尺度检验；60M/1B/est 首先报告**无校准 Spearman 秩相关**；校准后 RMSE 须把该尺度数据分半（校准/评估）并明确标注为"经目标尺度校准的分析"，不得与独立检验混称（AS-12 同步修订）。
3. **评分链补全**：v1 缺失的域级聚合公式补为 M1-EQ20；C1–C4 的输入与运算全部显式化（M1-EQ19），"同型/max"占位符消除；至此公式链闭合，权重、标量方向、冲突阈值列为**定稿前置条件**（见文末），关闭前本版本仍为草案。
4. **方向论证**：Required Expertise、modernbert_professionalism 及长度/数字比例类标量描述的是文本属性而非普适质量，不预设"越高越好"；新增**方向校验程序**（M1-EQ21）以数据规则判定方向；qurater 主合成口径相应调整为"经校验判定的正向维等权合成"。
5. **术语修正**：M1-EQ15 更名为**伪计数平滑替换**（additive pseudo-count smoothing）——它向全部分量加伪计数后重归一化，并非保持非零分量原比例的严格"乘性零值替换"；公式本体不变，正值与闭合性质不变。

### M1-EQ18（取代 EQ12）样本级质量分：hinge 冲突惩罚 + 乘性降权

$$h_i = \frac{\max\left(0,\; \tilde{c}_i - \tau\right)}{1-\tau} \in [0,1], \qquad Q_i = \left(\sum_{k=1}^{22} w_k \tilde{x}_{ik}\right)\bigl(1-\lambda h_i\bigr)$$

- **设计声明（回应审查）**：有意采用 hinge 形式——工作点 τ 以下的连续小冲突不惩罚，惩罚仅作用于超过判定阈值的超额部分；v1 的全局连续惩罚废弃。$\tilde{c}_i$ 为 M1-EQ19 的冲突度，τ 为抽查校准的判定阈值，$\lambda\in[0,1]$ 为冲突惩罚强度。
- **Q 范围证明**：$\sum_k w_k = 1$、$\tilde{x}_{ik}\in[0,1]$ $\Rightarrow$ $\sum_k w_k\tilde{x}_{ik}\in[0,1]$；$h_i\in[0,1]$、$\lambda\in[0,1]$ $\Rightarrow$ $(1-\lambda h_i)\in[1-\lambda,1]\subset[0,1]$；两个 [0,1] 量之积仍属 [0,1]。故 $Q_i\in[0,1]$，与 0–1 质量尺度相符，M1-EQ20 的域级中位数继承该范围。
- λ 校准同 v1：A1 抽查子集上使冲突修正后 Q 排序与人工判断的 Kendall τ 最大；敏感性含 λ=0（无修正）对照。

### M1-EQ19（取代 EQ13）冲突度完整定义：C1–C4 输入与运算显式化

记号：所有输入为归一化到 [0,1] 的量。正向分（越大越好）：`edu`=fineweb_edu、`flu`=fluency 压缩分、`reas`=reasoning 期望等级/5、`clean`=cleanliness 期望等级/5。负向原值（越大越差，作"噪声/广告强度"直接使用，**不做正向补转换**，因冲突对定义需要的就是"坏属性强度"）：`ad`=1−adfree 强度（即广告 logit 差归一）、`rep`=(top2gram+top3gram)/2 归一、`noalph`=非字母词占比归一。

$$c^{(1)} = \sqrt{\text{edu}\cdot\text{ad}} \quad \text{（教育价值高 × 广告强度高，题目典型情形）}$$
$$c^{(2)} = \sqrt{\text{edu}\cdot\max(\text{rep},\ \text{noalph})} \quad \text{（教育价值高 × 重复/非字母噪声强）}$$
$$c^{(3)} = \sqrt{\text{flu}\cdot(1-\text{clean})} \quad \text{（流畅度高 × 整洁度低，组间语义矛盾）}$$
$$c^{(4)} = \sqrt{\text{reas}\cdot\text{rep}} \quad \text{（推理要求高 × 简单重复强；unigram_entropy 若经 M1-EQ21 判定为"低熵=重复"方向，则以 } \max(\text{rep}, 1-\text{ent}) \text{ 替换 rep，否则不引入}）$$

$$\tilde{c}_i = \max\left(c^{(1)},c^{(2)},c^{(3)},c^{(4)}\right)\in[0,1]$$

- max 保留（取最严重的冲突对），但输入与运算至此全部显式，无占位符。
- 各输入的归一化方法与方向判定遵循 M1-EQ21 与 data_procee P03/P05；`ad` 由 M1-EQ09 的 adfree 取 1−(归一化 adfree) 得到。
- 判定与校准：$\tilde{c}_i>\tau$ 判为冲突样本，τ 由 A1 原文抽查校准（候选阈值下抽取冲突样本核验原文，选"确有冲突"比例可接受且召回合理的点）；A2/A3 去重后复验（AS-10/11）。

### M1-EQ20 域级聚合（补全 v1 缺失环节）

$$Q_d = \mathrm{median}\{\,Q_i : s(i)=d\,\}, \qquad \mathrm{disp}_d = \mathrm{IQR}\{\,Q_i : s(i)=d\,\}$$

- $s(i)$：样本 i 的源域标签（A1 由 `_source_domain`，A2/A3 由文件名推断）；$d$ ∈ 7 个质量信号域。
- $Q_d\in[0,1]$（继承样本级范围）；报告 $\mathrm{disp}_d$ 作为离散度；均值聚合仅作对照。
- 扩展集域级 Q 使用 A1 冻结标尺计算后与抽样集对应域对照（AS-11）。

### M1-EQ21 方向校验程序（不预设普适正向维）

对方向存疑维 $k\in\{$qurater 的 Required Expertise、modernbert_professionalism、rps_* 11 项标量、dsir_*$\}$：

1. 在每个质量域 $d$ 内计算秩相关 $\rho_d\big(x_{\cdot k},\,x_{\cdot}^{\text{base}}\big)$，基准 $x^{\text{base}}$ = 语义明确正向五维（fineweb_edu、fluency、reasoning、readability、cleanliness）的等权合成；
2. 判定规则：多数域（≥4/7）$\rho_d \ge \rho_{\min}$（默认 0.2，实跑时固定并记录）→ 接受正向；多数域 $\rho_d \le -\rho_{\min}$ → 判负向并补转换；否则 → 方向不定，**从主合成剔除、单列报告**；
3. qurater 主合成口径（修订 EQ11）：经本程序判定为正向的维等权合成（预期 Writing Style / Facts & Trivia / Educational Value 为正向，Required Expertise 待判定——其语义为"理解所需专业程度"，与 professionaliSM 一样是文本属性而非普适质量，对 github/IRC 等域方向可能反转）；被剔除维的 Q 敏感性（剔除/纳入/翻转三口径的域级排序 Spearman）纳入定稿前置实验。

- 依据：官方 Meta-rater 框架将上述维当质量维度使用，但其权重由"训练 Loss 最优"学习得到，与本题目语境（教材质量类比、跨 17 域可用性）不完全一致；域依赖方向必须由数据规则关闭。

### M1-EQ19'（v3 修订，限定 EQ18 的求和范围）样本级质量分

$$Q_i = \Big(\sum_{k\in S} w_k^{(S)}\, \tilde{x}_{ik}\Big)\bigl(1-\lambda h_i\bigr), \qquad S = \{k : \text{EQ21 判定入选（正向，或负向补转后正向）}\},\quad \sum_{k\in S} w_k^{(S)} = 1$$

- $S$：经 M1-EQ21 方向校验后的**入选指标集**；$w_k^{(S)}$ 为所选权重方案（等权/熵权）在 $S$ 上重新归一化后的权重。hinge 惩罚项 $h_i$、$\lambda$、$\tau$ 定义同 M1-EQ18；$Q_i\in[0,1]$ 证明不变（$\sum_{k\in S} w_k^{(S)} = 1$ 时求和仍属 [0,1]）。
- **被剔除指标 $k\notin S$ 的报告义务**：EQ21 的逐域 $\rho_d$ 判定依据、剔除/纳入/翻转三口径下 $Q_d$ 排序的 Spearman 敏感性，全部写入实验报告与 handoff.md——被剔除不等于沉默。
- **缺失值处理**：对 $S$ 中可用指标做等权平均，并按该行实际可用指标数重新归一化；若该行没有任何可用指标，则 $Q_i$ 记为缺失并不参与域级聚合。冲突度对可用的 C1–C4 分量取最大值；若四个冲突分量均缺失，则冲突标签记为缺失而不是无冲突。

### M1-EQ22 配比转移效应（组合影响的规范比较方式）

在单纯形上定义"从域 $a$ 转移配比质量 $m$ 到域 $b$"的路径（恒满足非负与和 1）：

$$p(t) = p + m\,(\mathbf{e}_b - \mathbf{e}_a), \qquad m \in [0,\, p_a]$$

- 等效**比例转移参数化**（推荐主口径，EXP-20260923-02 实测确定）：$m = r\cdot p_a$，$r\in[0,1]$——对任意域对（含极小配比域）恒可行；固定绝对量 $m$ 的口径对 $p_a < m$ 的域对不可行（ubuntu_irc 均值配比仅 1.96%，$m=0.05$ 超出可行域），故主分析用 $r=0.5$。

线性模型（M1-EQ17）下解析式（$a,b \ne \mathrm{ref}$；其他分量不变）：

$$\Delta_{a\to b}(m \mid p) = \hat y\big(p+m(\mathbf{e}_b-\mathbf{e}_a)\big) - \hat y(p) = \beta_a \ln\!\Big(1-\frac{m}{p_a}\Big) + \beta_b \ln\!\Big(1+\frac{m}{p_b}\Big)$$

- 边界情形：$b=\mathrm{ref}$ 时 $\Delta = \beta_a \ln(1-m/p_a)$；$a=\mathrm{ref}$ 时 $\Delta = \beta_b \ln(1+m/p_b)$。
- 性质：$\Delta_{a\to b} = -\Delta_{b\to a}$；效应依赖起点 $p$（对数结构的自然性质），报告时固定基线配比 $p^0$。
- **解释约束（写死）**：单个 $\beta_d$ 仅是"域 $d$ 相对参考域 ref 的对数比效应"，**不得**解释为域 $d$ 的独立收益；域间比较一律经 $\Delta_{a\to b}$ 表达，涉及 ref 的按边界情形式计算。

### M1-EQ23 双域组合分析（题目"各领域及其组合"的报告口径）

(a) **转移效应矩阵**（主分析）：基线 $p^0$ 取 A4 的 512 配方列均值（17 域均值配比，无量纲）；13 个有验证 Loss 域两两计算**比例转移** $\Delta_{a\to b}(r{=}0.5 \mid p^0)$（$m=0.5\,p^0_a$，见 EQ22 参数化），报告完整矩阵与 top-5 正/负转移对；不确定性用 bootstrap（512 配方重抽样 $B{=}1000$，重估 $\beta$ 后取 $\Delta$ 的 2.5%/97.5% 分位数；小规模验证 B=200）。
(b) **树模型数值对照**：同一批转移路径用 `HistGradientBoostingRegressor` 直接预测差，与 OLS-ALR 线性版并列；两法方向不一致的域对点名讨论。两者不视为同一算法。
(c) **多域组合实例**：至少一个三域组合案例（如 pile_cc 与 github 各 +0.05、wikipedia_en −0.10），报告模型预测差，展示组合效应与单域转移效应之和的差异（非线性交互存在时）。
(d) **ref 不变性（EXP-20260923-02 实测验证）**：更换参考域（pile_cc/wikipedia_en/arxiv）CV R² 完全一致——ALR 换 ref 仅为特征的线性重参数化，预测值与转移效应矩阵均不变；ref 选择只影响系数的表述基准（"相对谁"），论文中说明后任选一个解释上最方便的 ref。

### M1-EQ08 fluency_en（logit 对，官方顺序 [not_fluent, fluent]）

$$s_{\text{flu}} = z_2 - z_1 \quad (\text{fluent} - \text{not fluent})$$

- 方向：**正向**（取差后越大越流畅）。单位：logit 差（无量纲）。
- 原始分量顺序为 [不流畅, 流畅]；v0 的 z1−z2 记法因未指明分量含义作废，本式以位置 2 减位置 1 明确方向。
- 对照口径：argmax 类别（0/1）作二值化对照。

### M1-EQ09 ad_en（logit 对，官方顺序 [has_ad, no_ad]）

$$s_{\text{adfree}} = z_2 - z_1 \quad (\text{no ad} - \text{has ad})$$

- 定义为"无广告度"，方向：**正向**（越大广告越少）。单位：logit 差。
- 等价负向表述：广告度 = z1−z2（有广告−无广告）为负向指标，按题目要求补转换后与上式一致。两种表述取其一，本文统一用"无广告度"正向进模型，避免混用。

### M1-EQ10 modernbert_*（PRRC 框架，levels 0–5 六级 logits）

$$s_{\text{PRRC}} = \sum_{l=0}^{5} l \cdot \frac{e^{z_l}}{\sum_{m=0}^{5} e^{z_m}} \in [0,5]$$

- softmax 期望等级，方向：正向。单位：等级（0–5，无量纲）。
- 对照口径：argmax 等级（官方用法）作离散对照，二者秩相关性须报告。
- 适用字段：professionalism / readability / reasoning / cleanliness 共 4 项。

### M1-EQ11 qurater（QuRating 四维，官方顺序 [Writing Style, Required Expertise, Facts & Trivia, Educational Value]）

四维为四个独立评分维度（不是同一量的四分量），处理为四个子指标：$s_{\text{ws}}, s_{\text{re}}, s_{\text{ft}}, s_{\text{ev}}$，各自独立归一化后**等权平均**合成为 qurater 压缩分：

$$s_{\text{qur}} = \frac{1}{4}\left(\tilde{s}_{\text{ws}} + \tilde{s}_{\text{re}} + \tilde{s}_{\text{ft}} + \tilde{s}_{\text{ev}}\right)$$

- 方向：四维均正向（QuRating 语义）。单位：无量纲（归一化后 0–1）。
- 依据：Meta-rater 官方将四维作为独立 rater 分别赋权（0.05%/3.73%/4.77%/5.64%）， EDUCATIONAL VALUE 与 FACTS & TRIVIA 权重高、WRITING STYLE 近零——等权与官方权重两种聚合都保留，对比后择一并记录。
- 状态：等权为默认，官方权重聚合为对照（该对照仅作参考，不直接照抄权重，理由见 decisions.md）。

**Step2 量纲归一（同 v0 原则，标尺冻结见第 5 条修订）**：dsir_* 先长度混杂控制再分位数归一（方向按 DSIR importance 语义正向，具体语义与长度相关性实测确认，AS-03）；百分数组线性映射 [0,100]→[0,1]；计数/熵组 log(1+·) 后分位数归一；负向指标在进 M1-EQ12 前补转换 x→1−x（本题经 Step1 后全部指标已化为正向，负向补转换仅适用于 Step1 未覆盖的标量项）。

### M1-EQ12（v1 修订）样本级质量分与冲突修正

$$Q_i = \left(\sum_{k=1}^{22} w_k\, \tilde{x}_{ik}\right) - \lambda\, c_i, \qquad \tilde{x}_{ik}\in[0,1] \text{（方向统一后）}$$

- $Q_i$：样本质量分，无量纲；$w_k$：权重（Σw=1，熵权/组内等权+组间熵权，对照 Meta-rater 官方权重的相关性）；
- $c_i$：冲突度（M1-EQ13），无量纲 ≥0；$\lambda$：冲突惩罚系数，由 A1 抽查样本的排序一致性校准（见 M1-EQ13 说明），不是自由拍定参数。
- 冲突**不筛除样本**，直接进入 Q 的修正——回应"写清冲突如何改变最终 Q"。

### 模块二：冲突消解（v1 重写）

**两层结构**：第一层为**语义冲突对**（题目典型情形"教育价值高×广告含量高"属跨组冲突，组内极差无法识别）；第二层为组内不一致（辅助信号）。

**预定义语义冲突对**（依据：题目示例 + 指标语义，A1 原文抽查校准）：

| 冲突对 | 语义 | 不协调度定义（q 均为归一化正向分） |
|---|---|---|
| C1 教育 × 广告 | 教育价值高却含强广告信号 | $c^{(1)}_i = \sqrt{\tilde{s}^{\text{edu}}_{i}\,(1-\tilde{s}^{\text{adfree}}_{i})}$（双高分几何均） |
| C2 教育 × 重复噪声 | 教育价值高但重复度高（2/3-gram、非字母词） | $\max$ 同型几何均 |
| C3 流畅 × 混乱 | fluency 高而 cleanliness 低 | 同型 |
| C4 推理 × 简单重复 | reasoning 高而 unigram_entropy 低/重复高 | 同型 |

### M1-EQ13 冲突度与校准

$$c_i = \max_{j \in \{C1,\dots,C4\}} c^{(j)}_i \in [0,1]$$

- 冲突样本判定：$c_i$ 经 A1 原文人工/规则抽查确定工作点（在若干候选阈值下抽取冲突样本原文核验，选取"抽查确有冲突"比例可接受且召回合理的阈值），**不采用机械分位数阈值**（P95 会把 5% 样本强制标为冲突而不证明其确有冲突）。
- 报告：各冲突对的冲突率、按域/按长度分箱的分布；A2/A3 复验（去重后）主要结论一致性。
- $\lambda$ 校准：在 A1 抽查子集上取使"冲突修正后的 Q 排序"与"抽查人工判断"一致性（如 Kendall τ）最大的 λ ∈ [0, 1]，敏感性分析 λ=0（无修正）对照。

### M1-EQ15 伪计数平滑替换（v2 更名，原名"乘性零值替换"不严谨——非保比例乘性替换；公式本体自 v1 起不变）

- $\varepsilon$：替换质量占比（默认 10⁻³，敏感性 10⁻⁴/10⁻³/10⁻²），单位与 p 相同（无量纲比例）。
- 性质：正值、和恰为 1（对原行和归一化后的 p 使用；若原行和为 1 则上式恒保和 1）。

### M1-EQ16 ALR 变换

$$x_{jd} = \ln\frac{\tilde{p}_{jd}}{\tilde{p}_{j,\mathrm{ref}}}, \qquad d \in \{1,\dots,17\}\setminus\{\mathrm{ref}\} \quad (16 \text{ 维})$$

- 参考域 ref 候选：pile_cc（最大平均占比域）与 wikipedia_en，两档做敏感性分析。
- 约束回归备选（不作变换，直接在单纯形上带约束最小二乘/带惩罚），对照记录。

### M1-EQ17 主回归（ALR 线性）与非线性对照

$$y_j = \beta_0 + \sum_{d \ne \mathrm{ref}} \beta_d x_{jd} + \varepsilon_j$$

- 历史候选（未采用）：LightGBM（RegMix 原文同款）输入 17 维原始配比。该候选已被实际实现口径取代；最终使用 16 维 ALR 输入的 HistGradientBoosting。
- **Q 的引入方式（v1 修订：移除交互项）**：固定域级 $Q_{m(d)}$ 在本模型中不可识别——$p_{jd}Q_{m(d)}$ 是 $p_{jd}$ 的常数倍，与 $\beta_d$ 完全共线。故主模型与附加模型**均不含 Q 交互项**；Q 的用途限定为：(a) 系数横截面解释——检查 $\beta_d$ 与 $Q_{m(d)}$ 的秩相关（仅 6 个可映射域，观察性证据，不作因果与独立效应估计）；(b) 作为问题二的输入。若需估计质量的独立贡献，需要同一域内质量发生变化的实验数据（附件 A 不含，附件 B6–B8 含 Q 变异——归问题二）。

**验证与外推口径（v1 收紧）**

1. **去重**：A2/A3 复验前剔除与 A1 重叠的 id（A1 抽样集来自同源，重叠已实测证实）；去重后扩展集规模如实报告。
2. **标尺冻结**：归一化分位数锚点、log 变换参数、权重 $w_k$、冲突阈值与 $\lambda$ 全部在 A1 上确定后冻结，应用于 A2/A3 时**不得重新拟合**（可检验冻结标尺下扩展集分布偏移并报告）。
3. **跨尺度验证**：不直接比较 60M/1B 的绝对 RMSE（Loss 基线随规模变化）。口径：每尺度拟合尺度专属截距（配比系数共享）后比较残差 RMSE；并报告相对"该尺度均值预测"基线的 RMSE 下降百分比；系数漂移逐尺度报告（AS-05）。
4. **外推一致性**：A12–A15 仅做 **Spearman 秩相关**检验（rank invariance，RegMix ICLR 2025 的验证逻辑），不报告绝对误差、不参与估计（AS-06）。A12–A15 配比为 train 子集、Loss 为外推值，属有限一致性检查而非独立实测验证，论文中如实表述。
