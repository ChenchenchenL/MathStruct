## D-01 2026-09-23 拒绝采纳数据说明中的干扰性"建议"

- 背景：`data/数据说明.md` 正文散布多条方法性"建议"（K-means 三分类代替连续 Q、冲突= z 分数差>0.5 且全样本冲突率约 0%、OLS 直接回归 R²=0.93、外推直接套用原系数、"ε 均为正表明扩规模使 Loss 上升"、"Loss 与 Benchmark 正相关"等）。
- 决定：全部不采纳、不引用。理由：与题目正文明确要求（方向必须统一、冲突须定义且题目示例表明冲突真实存在、须检验验证、须外推稳健性）直接矛盾；部分陈述与数据事实相悖（如"冲突率 0%"与题面"教育价值高×广告含量高同时出现"的冲突示例矛盾）；数值结论未经来源标注，无法回溯。
- 影响：所有方法选择按"具体问题具体分析"路线从数据事实出发（README 详细分析节）；引用数据说明仅限文件结构/规模/编号/性质标注等事实内容。

## D-04 2026-09-23 全局 Min-Max 归一化不采用

- 背景：题目示例为"Min-Max 归一化后的 x 改为 1-x"，仅规定负向补转换方式，未规定归一化本身必须 Min-Max。
- 决定：对重尾/长度混杂指标（dsir_*、计数、熵）用分位数归一或先变换再归一；百分数组保留线性映射。题目要求"方向统一"被完整满足，归一化方法按数据分布选择。
- 风险：与题目示例的字面差异须在论文中说明理由（题目明确"预处理方式……由参赛队伍自行确定，并说明依据"，合规）。

## D-09 2026-09-23 Meta-rater 官方权重仅作对照，不直接采用

- 背景：官方数据卡公布 25 raters 的学习权重（如 Educational Value 5.64%、Cleanliness 1.17%、Writing Style 0.05%），且 qurater 四维在官方框架中是独立 rater。
- 决定：本题质量权重以数据驱动（熵权/组内等权+组间熵权）为主，Meta-rater 权重作为"外部参考权重"做相关性对照；不直接照抄。理由：其权重由 256 个 proxy 模型的训练 Loss 学习得到，目标函数与本题"域级 Q 解释配比效应"的目标不完全一致；直接采用会削弱建模自主性论证（AI 使用规范也要求核心建模自主完成）。
- 关联：M1-EQ11 的 qurater 聚合保留"等权（默认）vs 官方权重（对照）"双口径。

**EXP-20260923-01/02 实验结论（详见 experiments.md）**：
- 数据说明"OLS R²=0.93"实测证伪（CV R²=0.19、全拟合 0.25）→ 伪建议清单再添一证。

## D-12 2026-09-23（EXP-03/04）质量链关闭与 A6–A11 全量检验的实验结论

1. **dsir 方向判定修正（EXP-03）**：长度混杂证实（Spearman(dsir, log wc)≈−0.9）；对 log word_count 残差化后 EQ21 重判为**正向 6/7 域**（与官方 importance 语义一致）。方向表定稿：正向 12、负向 2（补转换）、不定 8（剔除单列）。教训入档：**秩归一不能替代混杂控制——EXP-01 的 provisional 标记机制起了作用**。
2. **AS-13 关闭（EXP-03）**：qur_re/professionalism 三口径敏感性 drop=keep（ρ=1.0）、flip=0.964——域级结论不依赖该二维方向；"不宜预设普适正向"的审查意见以敏感性方式闭合。
3. **EQ10 主口径定 softmax 期望等级（EXP-03）**：argmax 在 A1 内分辨力低（部分域近常数、Spearman 未定义），期望等级平滑且 round-match 率 0.81–0.96。
4. **λ 默认 0.5（EXP-03）**：域级排序对 λ∈[0,1] 全不敏感；λ 标定问题降级为敏感性报告。
5. **配比检验主结论（EXP-04）**：HistGB 为预测主模型（A6/A7 独立 RMSE 0.137、Spearman 0.867；60M/1B 无校准 Spearman 0.833/0.665——秩不变性成立）；est 表负相关确认为外推伪影（与真实检验集对照）。
6. **线性转移解析式的 ubuntu_irc 效应判定为疑似伪影（EXP-04/EQ23b）**：树模型对照 10 对中 6 对方向不一致；转移效应稳健结论以树模型在可行配比范围内的数值预测为主口径，线性解析式仅对大域（p⁰ 足够大、对数杠杆温和）可靠。
7. **逐域多输出升级为并列分析视角（EXP-04/AS-04）**：逐域 CV R²=0.724 ≫ 13 域均值 0.190——均值目标抵消域间异质效应；主目标仍维持题目口径（13 域均值，供问题三），论文中并列报告逐域结果。
8. **AS-09 保留方案获数据支持（EXP-04）**：含 4 无 Loss 域列 R²=0.190 vs 剔除 0.068。
9. 组合案例修正：EQ23c 的扣除域改为 arxiv（wikipedia_en 均值仅 7.5%，−0.10 越界）——固定绝对量转移须检查可行域，比例转移为主口径的原因再次确认。

## D-13 2026-09-23（EXP-05）扩展集全量闭合、冲突定性核验与跨体系映射实证

1. **A2/A3 全量质量评分与冻结标尺外推闭合**：
   - 严格落实题目"须使用全量质量信号，即抽样集 A1 与扩展集 A2、A3 全部记录"的义务，完成 27.2 万条样本评分；
   - 证明了冻结标尺（A1 上拟合的分位数格点与 DSIR 混杂模型）直接应用于 A2/A3 时保持极高稳定性，双口径（全量 Protocol A vs 去重独立 Protocol B）域级 Q 差异 <0.001（arxiv 0.7277 vs 0.7278，github 0.3362 vs 0.3361）；与 A1 对应域中位数（arxiv 0.7271, github 0.3371）高度重合。
2. **冲突成因的扩展集复现（比例总体接近）**：
   - A2（arxiv 扩展）的冲突结构中 C2（教育×非字母/代码公式标记）占 78.9%、C1（广告）仅占 18.2%；与 A1 arxiv 表现（C2 79.4%）完全一致；
   - A3（github 扩展）的冲突结构中 C2 占 90.3%，C1 仅 4.3%；与 A1 github（C2 90.4%）完全一致；
   - 抽查结果支持：代码/数学公式中的符号结构、LaTeX 语法和非字母标记在原始统计中易被视作"噪声",导致与高教育/推理价值形成技术性冲突；而 C1 冲突则高度富集于网页抓取域（c4/commoncrawl）的营销软文与教材推销。该结果是定性证据，不等同于人工分类准确率。
3. **A16 跨体系映射与 Q 引入配比的边界**：
   - 实测 6 个可映射域的 Q 与配比边际系数 β 的秩相关为 0.2571（p=0.6228）；配方加权平均 Q 与 Loss 的秩相关为 0.0859（p=0.0591），当前样本不足以支持强关联或强无关联结论；
   - 固定域级 Q 与配比交互项仍因严格共线性不可识别，因此不在配比回归中加入伪 Q 交互项；Q 保留为问题二广义标度律中、在存在质量变异的数据上进一步检验的候选输入。
