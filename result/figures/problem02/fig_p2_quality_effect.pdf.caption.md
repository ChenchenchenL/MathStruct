# 图注：数据质量对标度律的调节效应与 B8 异常数据诊断 (fig_p2_quality_effect)

- **数据来源**：附件 B6/B7 真实校准半合成质量干预集（360/450 点）与附件 B8 异常补充集（1,704 点）。
- **左图说明**：B7 扩展集上 6 组典型规模切片 $(N, D)$ 下，验证损失随数据质量 $Q$ 从 0.1 提升至 1.0 的衰减规律（散点为观测值，实线为广义标度律拟合曲线）。所有切片均呈现严格且平滑的单调递减规律。
- **右图说明**：相同规模切片（$N=0.7\text{B}, D=10\text{B}$）下 B7 与 B8 的直接对照。绿色实线展示了符合物理常识与标度律单调性的质量增益效应；红色虚线展示了 B8 中反常的“质量越高损失越大”正相关（$r = +0.9132$），排查证实其存在严重反常畸变。
- **核心结论**：
  1. 采用有效数据量指数模型 $L(N, D, Q) = E + A N^{-\alpha} + B D^{-\beta} e^{-\rho (Q - 1.0)}$，在保持 B1 经典参数不变的退化约束下，估计得到数据质量提升效率参数 $\rho = 0.6646 \pm 0.0135$（95% 置信区间 $[0.6275, 0.7013]$），拟合优度达到 $R^2 = 0.91607$，$\text{RMSE} = 0.09869$ Nats，$\text{MAE} = 0.07507$ Nats。
  2. 模型比较表明指数型在赤池信息准则（AIC = -2082.21）与贝叶斯信息准则（BIC = -2078.10）上均显著优于幂律模型（AIC = -1947.08）。
  3. 执行数据清洗规则 P2-02 隔离 B8 异常数据，保证了后续技术边际替代率（MRTS）推导与问题三优化模型的物理与逻辑正确性。
