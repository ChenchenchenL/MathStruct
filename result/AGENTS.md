# 结果产物规范

本文件仅约束 `result/` 目录及其子目录中的结果文件。这里保存建模和编码求解产生的图、表、模型输出和论文交付材料，重点保证结果可以直接用于学术论文、报告和复核。具体模型公式、原始数据、数据清洗过程和实验日志应分别记录在 `docs/`、`data/`、`src/` 等对应目录，不在本文件重复展开。

## 目录职责

- `figures/`：论文和报告使用的图片、矢量图、图注配套文件。**按问题分子目录存放**（如 `figures/problem01/`、`figures/problem02/`、`figures/problem03/`），严禁混放在根目录下。
- `tables/`：论文表格、统计汇总和可复核的数据导出。**按问题分子目录存放**（如 `tables/problem01/`、`tables/problem02/`、`tables/problem03/`），严禁混放在根目录下。
- `models/`：训练后模型、参数文件、预测结果和模型元数据。
- `submission/`：面向论文或竞赛提交的最终整理版本；必须能追溯到具体实验和代码版本。

题目数量、子问题数量和图表数量不固定。文件名不要依赖“最终版”“最新版”等易失名称，应包含题目/子问题、结果类型和版本或实验编号。各类图表与数据表严格归档至对应的 `problemXX` 子目录中。

## 图片规范

### 学术质量

- 图片必须由可复现脚本生成，记录脚本路径、实验 ID、数据版本和生成时间。禁止只保留手工截图作为唯一结果。
- 优先使用矢量格式 `PDF`、`SVG` 或 `EPS`；需要位图时使用 `PNG` 或 `TIFF`。照片、热图和栅格化输出建议至少 **300 dpi**，线稿、流程图和含细小文字的图建议 **600 dpi 或更高**。
- 导出时按最终排版尺寸计算像素，不要仅靠后期放大。位图宽度应满足目标版面；建议单栏图宽约 85 mm、双栏图宽约 170 mm，并在导出配置中明确尺寸。
- 线宽、字号、刻度和图例在最终尺寸下必须清晰可读；避免过细线条、压缩伪影、锯齿、透明度异常和字体替换。
- 使用统一字体、字号、线宽、配色和坐标轴样式；同一论文中的同类图应保持视觉一致。
- 颜色应兼顾黑白打印和色觉缺陷识别，不依赖单一颜色区分关键类别；必要时同时使用线型、纹理或标记。
- 坐标轴、刻度、图例、单位和必要的注释必须完整，数值精度与数据精度一致。
- 误差线、置信区间、样本量、显著性标记和统计检验方法必须在图注或配套说明中定义，不能让图形单独承担未解释的信息。

### 图内标题要求

- **图片内部不放总标题、论文标题或“图 1/Figure 1”等标题。**
- 图内可以保留必要的面板标记，如 `(a)`、`(b)`，但面板标记应简洁、位置统一，且不替代外部图注。
- 图注、图号、研究问题说明和完整解释写在论文正文、图注文件或 `submission/` 材料中，不嵌入绘图区。
- 不要把“结果分析”“模型效果”“实验结果”等叙述性标题写进图片；可使用必要的轴标签、单位、图例和局部注释。
- 生成脚本中关闭默认标题，例如 Matplotlib 使用 `ax.set_title(None)` 或不调用标题接口；其他绘图库应采用等效设置。

### 数学与单位

- 公式、变量和单位使用论文约定的数学排版；同一变量不得在不同图片中更换含义或单位。
- 坐标轴和图例中的单位必须明确，优先使用 SI 单位；百分比、概率和比例统一约定为百分数或小数，并在图注中说明。
- 对数坐标、归一化、标准化、截断、平滑、插值和变换必须在图注或元数据中注明。

## 图片文件与元数据

每张正式图片应有同名 `.yml` 或 `.json` 元数据文件，至少记录：

```yaml
figure_id: F01
experiment_id: EXP-YYYYMMDD-01
problem: problem-XX
source_data: data-dictionary 中的数据集 ID 和版本
script: src/...
code_version: 提交号或文件哈希
format: pdf/svg/png/tiff
dpi: 600
width_mm: 170
height_mm: 95
title_in_figure: false
caption: 图注应写在论文或配套文件中
notes: 坐标、单位、筛选条件、误差线和特殊处理
```

若图片由多个子图组成，元数据必须列出每个面板的含义、数据来源、单位和绘图顺序。图片文件名建议采用：`F01_problem-XX_result-v01.pdf`。

## 表格规范

- 表格数据必须保留可编辑版本，如 `CSV`、`XLSX` 或 `TEX`；不要只提交截图或嵌入图片。
- 表头写清变量含义和单位；缺失值、无法适用值、四舍五入规则和统计量定义必须说明。
- 小数位、有效数字和排序规则应与数据精度及统计不确定性一致。
- 表格中的每个关键数字都应能追溯到实验 ID、代码版本和输入数据版本。
- 论文中的表号、表题和解释写在外部文稿中；结果目录中的数据文件不强制嵌入表题。

## 模型与输出文件

- 模型文件必须附带元数据：模型版本、训练数据版本、特征顺序、单位/归一化方式、标签定义、参数配置、随机种子、训练代码版本和评估实验 ID。
- 预测结果或优化结果必须说明输出字段、单位、约束是否满足、异常值处理和后处理步骤。
- 压缩、转换或复制结果文件时不得丢失精度、坐标系、时间戳、单位和元数据。

## 交付前检查

提交或交给论文写作者前，逐项检查：

- 图片在最终排版尺寸下清晰，位图达到目标 DPI；
- 图内没有总标题、图号或冗余说明，必要的面板标记和轴标签清晰；
- 坐标轴、图例、单位、误差线和显著性标记均有定义；
- 配色可区分且兼容灰度打印和色觉缺陷阅读；
- 图、表、模型输出均能追溯到实验、数据和代码版本；
- 表格保留可编辑数据，关键数字未被手工改写；
- 文件名、元数据和版本号一致，`submission/` 中的最终文件与源结果一致；
- 结果只支持证据允许的结论，不把相关性写成因果性，不把单次运行写成稳定性能。
